## 1. 当前端到端链路

```text
信号源 50 Ohm 模式
 -> 板端 50 Ohm 对地终端（位于模拟滤波器之前）
 -> 外置约五阶模拟低通（截止频率约 800 kHz）
 -> AD9226，raw Fs = 5,120,060 Hz
 -> H_top 原始 16 bit AXIS
 -> adc_fir_axis
      |- 12 bit offset-binary 转 centered signed
      |- 39 taps Q1.17 FIR，抽取 3
      `- 对称舍入、signed16 饱和、4096 点 TLAST
 -> system.bd AXIS FIFO
 -> AXI DMA SG S2MM
 -> DDR 中 4096 x signed16，8192 byte
 -> PS g26_measurement_task
 -> CMSIS RFFT 候选搜索
 -> 2/3 整数谐波联合时域最小二乘
 -> 频率细化、模型选择、端到端幅相校准
 -> Upp / Urms / 基频 / 正频率分量 / 1、3 周期波形
```

当前没有模拟放大器。J11 串口屏由独立 HMI 任务驱动，测量结果和两组 640 点
模型波形保存在带 generation 的 `g26_measurement_output_t` 快照中。

## 2. PL 数据契约

| 项目 | 当前值 |
| --- | ---: |
| ADC 原始采样率 | `5,120,060 Hz` |
| FIR 抽取 | `3` |
| PS 分析采样率 | `1,706,686.667 Hz` |
| 帧长度 | `4096 samples` |
| DMA 长度 | `8192 byte` |
| PS 样点格式 | `signed int16` |
| FFT 真实频点间隔 | `416.672 Hz` |

活动 FIR 由 `fir_compiler_0` 实现，量化系数和为 `2^17`：

| 指标 | 设计值 |
| --- | ---: |
| taps / order | `39 / 38` |
| 通带 | `0..500 kHz` |
| 500 kHz | `-0.008071 dB` |
| 阻带起点 | `1 MHz` |
| 1 MHz | `-67.630308 dB` |
| 阻带最差 | `-67.149421 dB` |

`adc_fir_axis` 在 FIR 输出握手时计数并每 4096 个抽取后样点产生一次
`TLAST`。PS 不得再执行旧 raw ADC 路径中的 `u16 >> 4` 或额外 PS FIR。

## 3. PS 测量流程

```text
ARMED
 -> KEY1/HMI START
 -> LIVE：DMA 对齐并丢弃至 TLAST
 -> 丢弃 3 个预热帧
 -> 采集 1 个正式帧
 -> 检查 8192 byte、DMA 和 FIFO monitor
 -> 分析、校准、生成 1/3 周期波形
 -> 刷新当前时间域/频域页
 -> 自动请求下一 generation 并回到 LIVE
 -> KEY2/HMI STOP 清屏并重新 ARMED
```

当前连续显示仍逐 generation 复用一帧 SG DMA 快照，不实现多 BD 环形采集。
每轮重新对齐并预热，输入变化后下一完整 generation 会覆盖波形、Upp/Urms、
基频和频谱分量；分析失败时清除旧画面并自动重试。正式帧期间
`blocked_reset` 增长会拒绝结果，`blocked_high_watermark` 当前仅告警记录。
常规双音板测约 `80..340 ms`，三分量测试约 `570 ms`，均满足 2 s 要求。

## 4. 活动算法

1. 对 4096 点数据估计并去除 ADC 中点偏置。
2. Hann 窗加 CMSIS 4096 点 RFFT 只用于候选频率搜索。
3. 由候选构造满足整数谐波关系的基频假设。
4. 在未加窗时域数据上联合拟合 DC 与 2/3 组 `sin/cos` 系数。
5. 围绕基频做 4 轮、每轮 5 点的残差最小化频率细化。
6. 用 BIC 在二分量和三分量模型间选择。
7. 拟合基波必须同时满足 `3 sigma` 和 `0.5 mVpeak` 最小门限，避免
   `200/400 kHz` 被误解释成 `11.765 kHz` 的 H17/H34。
8. 对每个分量应用频率相关幅值和相位校准，再统一重算 `Urms`、`Upp`
   和波形。

拟合模型为：

```text
x[n] = DC + sum(a_k sin(w_k n) + b_k cos(w_k n)) + error[n]
A_k  = sqrt(a_k^2 + b_k^2)
```

真有效值使用 `sqrt(sum(A_k^2 / 2))`。`Upp` 使用拟合幅相在一个基波
周期内重建 4096 点后求最大值减最小值，不使用原始稀疏样点的裸
`max-min`。

绝对相位随 DMA 起点变化，不是显示指标。相位校准前，250/500 kHz
零相位双音的 ADC 侧相对相位约为 `-0.36 rad/-20.6 deg`。当前先从每个
分量的拟合相位中扣除输入到 ADC 的 `theta(f)`，再使用
`phase_k - harmonic_order_k * phase_1`；优化后同一组合实测约为
`+0.022 rad/+1.25 deg`。

## 5. 当前端到端校准

全局直连比例为：

```text
APP_G26_DIRECT_MV_PER_CODE = 2.3096181 mV/code
```

频率相关幅值补偿按分量频率线性插值：

| 频率 | 补偿系数 |
| ---: | ---: |
| 10 kHz | `1.049817` |
| 200 kHz | `1.019856` |
| 250 kHz | `1.013588` |
| 300 kHz | `0.989776` |
| 400 kHz | `0.952547` |
| 500 kHz | `0.962268` |

该校准覆盖当前 50 Ohm 终端、模拟滤波器、ADC、PL FIR 和码值换算。更换
终端、模拟滤波器、ADC 输入网络、PL 缩放或供电后必须重新标定。不能恢复
旧滤波器使用的 `1.04` 经验补偿，也不能使用旧放大链的
`0.1645 mV/code`。

输入到 ADC 的展开相位按下列节点线性插值：

| 频率 | 相位 | 频率 | 相位 |
| ---: | ---: | ---: | ---: |
| 10 kHz | -2.8 deg | 200 kHz | -58.0 deg |
| 20 kHz | -5.6 deg | 250 kHz | -73.8 deg |
| 40 kHz | -11.1 deg | 300 kHz | -90.0 deg |
| 50 kHz | -14.5 deg | 350 kHz | -107.0 deg |
| 100 kHz | -28.0 deg | 400 kHz | -127.0 deg |
| 150 kHz | -43.3 deg | 450 kHz | -147.0 deg |
| - | - | 500 kHz | -169.6 deg |

对第 `h_k` 次谐波，输入参考相对相位为：

```text
delta_k,input = (phi_k - h_k*phi_1)
              - (theta(f_k) - h_k*theta(f_1))
```

该表只适用于当前模拟链路；更换滤波器或 ADC 输入网络后必须重测。

## 6. 当前板测证据

### 6.1 幅值与频率

- 10..500 kHz、理论 `50 mVpeak` 的多组结果约为
  `49.439..50.501 mVpeak`，最大绝对误差约 `0.561 mV`。
- 理论 `25 mVpeak` 的补测中最大分量误差约 `0.363 mV`。
- 两个 `25 mVpeak` 分量的 `Urms` 理论值为 `25 mV`，补测最大误差约
  `0.240 mV`。
- 频率误差通常为 `0..3 Hz`。
- 等幅与不等幅测试表明 400 kHz 分量幅值加倍后测量比例约为 `2.003`。

### 6.2 1..2 MHz 单频干扰

有效信号固定为 250/500 kHz、各 `50 mVpeak`，分别叠加
`200 mVpp` 的 H4/H6/H8 干扰。最近一组基准和每种干扰两次测试的均值为：

| 工况 | H1 mVpeak | H2 mVpeak | Urms mV | Upp mV |
| --- | ---: | ---: | ---: | ---: |
| 无干扰 | 49.987 | 50.009 | 49.998 | 174.908 |
| 1 MHz | 50.028 | 49.953 | 49.991 | 174.854 |
| 1.5 MHz | 49.933 | 49.987 | 49.960 | 174.792 |
| 2 MHz | 49.991 | 50.029 | 50.010 | 174.958 |

干扰前后最大参数变化小于 `0.2 mV`，全部结果为 2 个分量、基频
`250000 Hz`，测量时间 `310..340 ms`。这证明抽取前数字 FIR 对 1.5 和
2 MHz 的潜在抽取混叠有效，也证明 1 MHz 阻带边界测试通过。

模拟滤波器在 1 MHz 单音测试中约为 `100 mVpp -> 20 mVpp`，即约
`14 dB` 衰减。与 FIR 的 1 MHz `67.63 dB` 相加，典型级联衰减约
`81.6 dB`；按 FIR 阻带至少 60 dB 保守计算，总衰减不低于约 `74 dB`。

### 6.3 可观测性

当前串口同时报告 DMA 状态、实际帧长、FIFO 质量、分量数、基频、各分量
幅相、DC、归一化残差、BIC、`delta_bic` 和测量时间。该信息已用于定位：

- 50 Ohm 配置错误导致的整体倍频；
- 新校准表与旧自检预期不一致导致的 `code=90`；
- `0.106 mVpeak` 伪基波导致的 `11.765 kHz/H17/H34` 模型。

当前启动日志为 `PASS: algorithm self-test`。

### 6.4 相位补偿前后

- 250/500 kHz、两分量各 `100 mVpp`、设定相位均为 0 deg：优化前
  `A1/A2=49.899/49.885 mVpeak`、相对相位 `-20.569 deg`、
  `Upp=174.567 mV`；优化后 `A1/A2=49.895/49.952 mVpeak`、相对相位
  `+1.250 deg`、`Upp=175.752 mV`。
- 优化后 100/200、150/300、250/500 kHz 三组中，相位残差对 Upp 的
  计算影响均不超过约 `0.004 mV`；剩余约 0.3..1.1 mV 的理想值偏差由
  分量幅值不恰为 `50.000 mVpeak` 主导。

### 6.5 raw ADC 精确危险折叠点

以 100/200 kHz 为有效双音、日志中两分量约 `100 mVpeak`，通过加法器
叠加标称 `250 mVpp` 干扰，已测试：

| 干扰频率 | 理论折叠 | 额外拟合线 | Upp mV | Urms mV |
| ---: | ---: | ---: | ---: | ---: |
| 4.720060 MHz | 400 kHz | H4 0.732 mVpeak | 351.235 | 99.829 |
| 5.520060 MHz | 400 kHz | H4 0.682 mVpeak | 351.472 | 99.845 |
| 4.620060 MHz | 500 kHz | H4 0.557 mVpeak | 351.273 | 99.799 |
| 5.620060 MHz | 500 kHz | H3 0.615 mVpeak | 352.235 | 99.923 |

相对 `Upp=352.035 mV/Urms=100.000 mV` 的理论基线，四点的 Upp、Urms
和有效分量幅值误差均小于 1 mV。当前定量混叠风险较低；但输入实际只有
H1/H2 时算法多次把不足 1 mV 的 H3/H4 选为第三分量，合法 5 mVpeak
弱分量测试完成前不调整门限。完整原始数据见详细实测记录。
