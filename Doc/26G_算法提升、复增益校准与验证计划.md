## 0. 先给结论

1. 用户对截图证据的质疑成立。截图只覆盖干净单音，而且 50、150、250 kHz 在队友的
   `1.28 MSPS / 4096` 链路上分别恰好是第 160、480、800 个 FFT bin。它不能证明
   非整 bin、多谐波、弱基波、噪声、滤波衰减和高频干扰下仍满足题目指标。
2. 但“当前尚未加入最小二乘”已经不是工作区事实。当前
   `g26_signal_analysis.c` 已实现 `DC + 2/3 组 sin/cos` 的联合最小二乘、整数谐波
   组合搜索、模型残差、幅相重建 `Upp` 和模型 `Urms`。后续不应再另写一套重复的
   “最小二乘算法”。
3. 这不是一般意义上的盲源分离。题目给出了非常强的先验：只有一个基频、1 或 2 个
   整数次谐波、共 2 或 3 根有效谱线。因此正确问题是“带整数谐波约束的低维参数
   估计和模型选择”。不需要 MUSIC、ESPRIT、ICA、压缩感知或逐根相减。
4. 当前最需要补的不是 FFT 点数，而是：
   - 独立且覆盖真实困难工况的测试；
   - 2/3 分量模型的复杂度惩罚和明确拒绝条件；
   - 端到端、频率相关的复增益校准；
   - 多帧一致性、DMA/FIFO/削顶等质量门控；
   - 查表节点之外的整机闭环验收。
5. 滤波器补偿不能只有幅度衰减表。频谱幅值和 RMS 主要依赖幅频响应，合成波形和
   `Upp` 还依赖各谐波的相对相位，所以最终对象应是完整链路复增益 `H(f)`。
6. 查表和最小二乘都不能修复 ADC 前已经发生的混叠、削顶或互调。第三问能否成立，
   仍首先取决于模拟抗混叠滤波和前端线性度。

## 1. 成功标准和固定前提

### 1.1 题目验收目标

| 项目 | 硬性指标 | 本计划内部目标 |
| --- | ---: | ---: |
| 合成波 `Upp` | 绝对误差 `<= 5 mV` | 主机无噪测试 `<= 2 mV`，整机保留点 `<= 4 mV` |
| 真 `Urms` | 绝对误差 `<= 5 mV` | 同上 |
| 各分量峰值 | 绝对误差 `<= 5 mV` | 同上 |
| 基频 | 绝对误差 `<= 1 kHz` | 内部估计 `<= 250 Hz` |
| FFT 真实频点间隔 | `<= 500 Hz` | 当前约 `416.67 Hz`，保持不变 |
| 操作到稳定显示 | `<= 2 s` | 单次算法 `< 100 ms`，其余时间留给采集、重试和 HMI |

内部目标比题目严格，是为了给信号源误差、模拟链漂移、校准插值、ADC 非线性和显示
取整留余量。最终是否通过只按题目硬性指标判断。

### 1.2 当前固定数字契约

```text
ADC nominal Fs          = 5,120,060 Hz
PL FIR decimation       = 3
analysis Fs             = 1,706,686.667 Hz nominal
DMA frame               = 4096 x signed int16
DMA bytes               = 8192
frame duration          = about 2.400 ms
FFT bin width           = about 416.67155 Hz
useful band             = 10 kHz to 500 kHz
valid component count   = 2 or 3
```

在开始算法修改前，必须用实际 XSA、RTL、BSP 和一帧 DMA 数据再次闭合以上契约。
当前 `.ai/PLagriculture.md` 的部分描述仍是 FIR 前 raw AXIS，而最新工程文档和当前
`hardware_config.h` 是 FIR `/3` 后 `signed int16`。该矛盾必须先消除，不能让算法在
错误的采样率或码型上得到“看起来合理”的结果。

### 1.3 算法成立所需物理前提

- 完整模拟和数字链在有效信号范围内近似线性时不变；
- 放大器和 ADC 未削顶，滤波器未产生明显幅度相关失真；
- ADC 前的模拟低通已把会混叠进 `0--500 kHz` 的干扰压到误差预算内；
- 每帧 4096 点是等间隔样本，没有 DMA 停顿造成的时间缺口；
- 题设有效信号确实由基波和 1 或 2 个整数次谐波构成；
- 每个有效分量的峰值 `>= 5 mV`，但基波不保证最强；
- 频谱分量幅值指正弦峰值，不是峰峰值或有效值。

若任一前提不成立，算法应拒绝本帧或重采，而不是继续输出一个高置信度数值。

## 2. 现有截图能说明什么，不能说明什么

截图中的四组结果对板级调通仍有价值：

- DMA 能取得完整帧；
- 干净单音下频率、RMS、拟合幅值和重建 `Upp` 彼此一致；
- 单次总耗时约 `23 ms`，说明 Cortex-A9 算力不是主要瓶颈；
- 12 bit ADC 配合长帧参数估计具有达到 5 mV 指标的潜力。

但它不能作为正式算法验收，原因如下：

1. 输入只有 1 根谱线，而正式题目固定是 2 或 3 根；
2. 测试频率恰好落在队友链路的 FFT bin，未触发频谱泄漏和分量串扰；
3. 只测了 200/250 mVpp，未覆盖 50 mVpp 总信号和 5 mVpeak 弱分量；
4. 没有随机噪声、毛刺、直流偏置、非谐波杂散和不同相对相位；
5. 日志使用 `AD9226_manual_nominal` 标称换算，不是最终端到端校准；
6. 截图链路是 16384 点 raw ADC 加 PS FIR `/4`，不是当前 PL FIR `/3` 的 DMA 契约；
7. 没有保存 raw frame、输入设置、实际接线、重复统计以及 bit/XSA/ELF 哈希；
8. 没有模拟滤波器幅相、放大器增益变化和第三问高频干扰的闭环证据。

因此该截图的正确定位是“单音 bring-up 通过”，不是“G 题算法通过”。

本次审查已使用 `arm-none-eabi-gcc` 的 Cortex-A9 `-O2 -Wall -Wextra -Werror`
配置编译现有 host test，并在 Xilinx Zynq QEMU 中运行，结果为：

```text
G26 signal analysis self-test passed
```

这证明当前 4 个内置用例和 ARM/CMSIS 构建可运行，但不能外推为完整算法通过。截图的
“单音、整 bin”证据缺陷只适用于外部 Calvin 板测，不应错误描述成本地自测完全没有
非整 bin 或谐波覆盖。

### 3.1 当前最优先的三个算法缺口

1. **模型阶数偏置**：三分量模型参数更多，SSE 天然不会比对应二分量模型更差。
   仅选残差最小模型会把噪声或杂散拟合成第三根有效谱线。
2. **有指标、无门控**：残差被打印，但高残差、次优模型接近、弱分量不显著时，
   `g26_signal_analyze()` 仍可能返回成功。
3. **标量校准**：当前先用单一 `mV/code` 把整帧转成 mV，无法对每个谐波分别修正
   LC、放大器、匹配网络、ADC 和 FIR 的频率相关复增益。

### 3.2 暂时不要做的重写

- 不更换 CMSIS FFT；
- 不增加 FFT 点数或用零填充冒充分辨率；
- 不把联合最小二乘改回逐分量投影或逐根相减；
- 不立即引入通用矩阵库；
- 不立即上非线性全局优化；
- 不为“信号分离”引入 MUSIC、ICA、ESPRIT 或机器学习；
- 不在算法尚未建立可靠测试前修改 PL 采样率和 FIR 主链。

## 4. 统一信号模型

对于一个候选谐波集合 `H={1,h2[,h3]}`，在 ADC/FIR 观测域拟合：

```text
y[n] = c + sum_h (a_h*sin(2*pi*h*f0*n/Fs)
                   + b_h*cos(2*pi*h*f0*n/Fs)) + e[n]
```

其中：

- `c` 是观测域直流；
- `f0` 是共同基频；
- `h` 是整数谐波阶次；
- `a_h,b_h` 是 FIR code 域的正交系数；
- `e[n]` 包含量化噪声、随机噪声、未建模杂散和错误模型残差。

固定 `f0` 和 `H` 后，该问题对参数是线性的：

```text
beta_hat = argmin ||y-X*beta||^2
A_code,h = sqrt(a_h^2+b_h^2)
phi_code,h = atan2(b_h,a_h)
```

完整链路在频率 `f` 的复增益定义为：

```text
H(f) = C_code(f) / C_input_mV(f)
C = a + j*b
```

校准后的输入端复幅值为：

```text
C_input,h = C_code,h / H(h*f0)
```

这一步应发生在联合拟合之后。搜索和残差仍可在 code 域完成，避免为了频率相关校正
先对整帧做一个并不存在的“统一 mV/code”转换。

## 5. 目标算法链

```text
帧完整性和硬件状态检查
 -> 去直流，Hann + CMSIS RFFT
 -> 10--500 kHz 局部峰和噪声底估计
 -> 500 Hz 栅格上的基频/谐波假设
 -> 未加窗数据的联合最小二乘
 -> BIC 模型选择、残差和歧义检查
 -> 必要时只对最佳模型做共同 f0 一维细化
 -> 每根谱线分别做端到端复增益校正
 -> 多帧一致性检查
 -> 统一重建 Upp、Urms、谱线和 1/3 周期波形
 -> 结果有效或明确拒绝并重采
```

### 5.1 第一道门：帧质量

以下任一情况出现时直接拒绝，不进入 FFT：

- DMA 完成长度不是 8192 bytes；
- TLAST/帧对齐失败；
- FIFO reset、full/prog_full、高水位阻塞或 DMA 错误影响分析帧；
- ADC 原始 12 bit 已削顶，或 FIR 数值已饱和；
- 同一帧包含停顿前后的非等间隔数据；
- 样本全常数、明显异常或出现非有限计算结果。

当前 `signed int16 == -32768/32767` 只能判断 FIR 输出饱和，不能证明 AD9226 未削顶。
最终必须有 ADC 原始削顶或足够接近满量程的可见状态。当前高水位变化只是 WARN，
需要用板测定义哪些计数变化会污染帧，然后升级为可执行的拒绝规则。
若冻结 PL 阶段暂时无法增加 raw ADC 近轨计数，则运行时必须把 `clip_status` 标为
`UNKNOWN`，并用最坏幅值/相位组合的板测证明动态余量；不能把 FIR 未饱和写成 ADC
未削顶，也不能把该帧标为最高置信等级。

当前 SG DMA 实际仍是单 BD 逐帧提交。帧长和 TLAST 正确不等于样本时间轴一定连续；
必须通过 FIFO 计数、背压实验和预提交的小型 BD ring 证明分析帧内没有采集停顿，再把
该帧交给频谱和最小二乘。这里不需要建设通用 DMA 框架，只需满足固定 8192-byte 帧。
同时必须核对 monitor 的实际探针位置：当前部分 AXIS/frame 计数观察的是 FIR 前 raw
stream，不能直接用来证明 FIR `/3` 后送入 DMA 的 4096 点分析帧连续且完整。

### 5.2 FFT 只做搜索，不做最终幅值

保留当前 Hann 和 coherent-gain 修正，用 FFT 完成：

- 10--500 kHz 内局部峰搜索；
- 连续频率初值 `f_fft`；
- 候选排序；
- 非峰 bin 的稳健噪声底估计。

不要把 FFT 峰值直接当最终分量幅值。非整 bin 时，即使补了 Hann coherent gain，
峰值仍受 scalloping、邻近分量和频率偏差影响。最终幅相只取自未加窗联合拟合。

候选门限不要使用“最强峰的固定百分比”，否则强谐波会掩盖 5 mVpeak 弱基波。
初期保留绝对低门限和 16 个候选；得到输入短接噪声后，再改为：

```text
candidate_threshold = max(低于5mV的保护下限, k * 实测频谱噪声底)
```

### 5.3 谐波假设和频率处理

保留两种频率概念：

- `f_fft`：抛物线得到的连续频率，只用于候选匹配和质量诊断；
- `f_grid`：吸附到 500 Hz 的题设频率，用于构建整数谐波假设和最终报告。

当前链路的 bin 约为 `416.67 Hz`，而题设频率步进为 `500 Hz`。500 Hz 栅格相对
FFT bin 的小数偏移会周期性出现约 `0、+0.2、+0.4、-0.4、-0.2 bin`。测试必须
覆盖这五类，不能只测 50、150、250 kHz 这类近整 bin 点。

现有自测中的 50.5 kHz 已覆盖其中一种非整 bin 情况，但单个用例不能代表五种偏移、
不同谐波阶次、相位、噪声和幅值组合。

第一版继续使用题设 500 Hz 先验，不立即增加非线性优化。只有最坏 `+/-0.4 bin`、
实测采样钟误差和信号源失谐造成幅值或相位误差超出内部目标时，才对最优的 1--2 个
模型增加共同基频的一维 variable projection：

```text
SSE(f0) = min_beta ||y-X(f0)*beta||^2
```

建议以各谱峰连续估计按谐波阶次加权得到初值，在题设栅格附近做少量 SSE 评估和
抛物线细化。所有分量始终强制为同一个 `f0` 的整数倍。拟合使用连续 `f0`，显示值
仍可报告最近的 500 Hz 题设栅格。

### 5.4 弱基波处理

第一版不增加额外算法，先验证当前规则能否稳定发现 `5 mVpeak` 基波。因为当前没有
相对最强峰门限，且候选容量为 16，理论上只要噪声和校准允许，弱基波应进入候选。

当前 `4.5 mV` 最小分量检查发生在固定标量换算之后、频率响应校正之前。最终实现中，
“是否达到题设 5 mVpeak”必须在复增益校正后的 BNC 输入域判断；校正前的 code 域
只能使用按最坏通带增益和实测噪声推导的宽松检测门限。否则 500 kHz 衰减就可能先把
合法弱线删掉，使后续查表永远没有机会恢复它。

必须测试：

- H1=`5 mVpeak`，高次谐波接近动态范围上限；
- 非连续阶次，如 `{1,3,4}`、`{1,7,19}`；
- 最高谐波接近 500 kHz；
- 带内非谐波杂散比 H1 更强。

只有测试证明 H1 经常无法形成 FFT 候选时，才增加有限回退：由强峰 `f_i` 和可能
阶次 `h` 反推少量 `f0=round((f_i/h)/500)*500` 假设，然后强制联合模型包含 H1。
不无条件穷举 10--500 kHz 全部组合。

### 5.5 联合最小二乘和数值稳定性

继续同时拟合 DC 和所有分量，不能逐根拟合后相减。最多 7 个未知量，且有效谐波
至少相差 10 kHz，在约 2.4 ms 记录内基函数通常接近正交。当前 `float32 + 7x7`
带主元求解器很可能足够。

实施时增加以下诊断：

- 最小主元或正规矩阵条件性代理；
- `SSE`、`SST`、残差 RMS；
- 解向量是否有限；
- 每根分量的幅值和近似不确定度。

只有条件性测试失败或双精度参考对比显示数值误差超过预算时，才把正规方程改为
QR/Cholesky 等求解方式。不要仅因“理论上 QR 更稳定”就先引入更多代码。

### 5.6 2/3 分量模型选择

不能继续只选 SSE/归一化残差最小的模型。建议保存每个有效模型的 `SSE`，使用 BIC：

```text
p   = 1 + 2*M                  # DC + M组sin/cos
BIC = N*ln(SSE/N) + p*ln(N)
```

若共同 `f0` 也由连续优化得到，则 `p` 再加 1。选择 BIC 最小模型，并保存最优与
次优的 `Delta BIC`。这样第三根线必须带来足够的残差下降，才能抵消两个新增参数。

可用以下值作为测试初值，不直接当最终硬编码结论：

| `Delta BIC` | 初始处理 |
| ---: | --- |
| `> 10` | 模型证据强，可继续其他质量检查 |
| `6--10` | 重采一帧并检查一致性 |
| `< 6` | 模型歧义，不发布结果 |

最终阈值必须由带噪合成数据、真实短接噪声和板测 ROC/误判统计确定。

### 5.7 置信度不做成虚假的百分数

最小二乘可提供残差和近似协方差：

```text
sigma2    = SSE / (N-p)
Cov(beta) ~= sigma2 * inv(X^T X)
```

但真实残差可能经过滤波而相关，不能直接把理论 95% 区间包装成“97% 置信度”。第一版
应输出可解释的质量状态和原始指标：

- `frame_valid`：DMA/FIFO/削顶是否合格；
- `NRMSE=sqrt(SSE/SST)`；
- 残差 RMS 和频谱噪声底；
- 每根分量的幅值、近似标准差或幅值/噪声比；
- 最优和次优模型的 `Delta BIC`；
- 拟合残差中的最大未解释谱线；
- `f_fft` 到题设栅格的距离；
- 最小数值主元或条件性代理；
- 2--3 帧的模型、幅值和相对相位稳定性。

对外只需要明确状态，例如：

```text
VALID
RETRY_LOW_CONFIDENCE
REJECT_FRAME_ERROR
REJECT_CLIPPED
REJECT_MODEL_AMBIGUOUS
REJECT_HIGH_RESIDUAL
```

高残差、模型歧义、分量统计不显著、帧异常或削顶时，必须在 2 s 预算内重采；不能
沿用上一帧数值冒充本次结果。

### 5.8 多帧一致性

单个分析帧只有约 2.4 ms，2 s 时间预算足以分析多个帧。建议在单帧算法通过后，再
加入 2--3 个连续有效分析帧的一致性门控：

- 谐波根数和阶次必须一致；
- 基频栅格必须一致；
- 幅值差应落在实测重复性阈值内；
- 比较相对相位 `psi_h=phi_h-h*phi_1`，消除采集起点平移；
- 选中位数结果或残差最小且与其他帧一致的结果，不直接平均不同起点的原始样本。

多帧一致性是经验置信度的重要来源，但应在单帧算法和 DMA 连续性先通过后加入。

## 6. 滤波器和完整链路复增益查找表

### 6.1 校准对象

最终校准对象固定为：

```text
BNC 输入 mV
 -> 51 Ohm 负载下的 LC
 -> 放大器
 -> 51/50 Ohm 源负载匹配
 -> AD9226
 -> PL 39 taps FIR /3
 -> DMA signed FIR code
```

不分别给 LC、放大器和 ADC 各乘一个理论系数再叠加。端到端测量可以直接吸收电阻
公差、ADC 增益、FIR 增益和实际接线差异，也能避免再次错误补偿 50 Ohm 二分压。

### 6.2 为什么需要复增益，而不是只有衰减

对单根谱线，线性滤波只会改变该频率的幅值和相位，不会把它变成另一个源。因此：

- 频谱峰值需要除以 `|H(f)|`；
- 模型 `Urms` 需要使用校准后的各分量幅值；
- `Upp` 和波形需要校准后的幅值及相对相位；
- 纯线性时延只平移波形，不改变 `Upp/RMS`；真正危险的是非线性相位和幅频起伏。

只做幅度表时，频谱和 RMS 可能通过，但不同谐波相位组合下的 `Upp` 仍可能失败。

### 6.3 初始校准节点

先使用当前文档已经建议的最小频率集合：

```text
10, 50, 100, 200, 300, 400, 450, 500 kHz
```

在 400--500 kHz 附近，若中点保留测试显示插值误差超预算，再增加 350、425、475 kHz
等节点。不要在实测之前无条件做一张很密的表。

幅度方面先在动态范围两端 50 和 250 mVpp 建立重复测量，并用 100/200 mVpp 作为
不参与建表的线性保留点。若两档得到的增益差折算到最坏分量仍小于约 1 mV，则使用
一维频率表；只有确认
放大器压缩或 ADC 增益随幅度变化造成超预算，才升级成频率 x 幅度二维表。
若确需二维表，运行时先用中间/一维校正得到一次总 `Upp`，再沿幅度轴线性插值并
重算一次即可，不做反复迭代。

还要用包含 `5 mVpeak` 弱分量的多音验证低端可检测性。不能只因单音 100/250 mVpp
线性，就默认 5 mVpeak 分量的偏差和噪声也合格。

### 6.4 每个校准点必须保存的字段

```text
frequency_hz
input_peak_mv
gain_code_per_mv
transfer_phase_rad
dc_code
repeat_count
gain_stddev
phase_stddev
source_load_mode
board_temperature
bit_xsa_elf_hash
raw_capture_reference
```

相位表不能通过多次不同步的单音 DMA 相位直接相减得到，因为每次采集起点未知。
必须采用以下任一有共同相位参考的方法：

1. 双通道示波器同时测 BNC 输入和 ADC 前模拟节点，并共同触发；
2. VNA/频响分析仪；
3. 已知相对相位、相干生成的多音校准，并有独立参考验证。

双通道示波器/VNA主要得到模拟链路传递相位；PL FIR 的复响应应由最终 COE/脉冲响应
计算并通过板上数据核对，再与模拟响应合并。任意 DMA 起点造成的公共时间平移不应
被误记成滤波器非线性相位。

如果暂时无法测相位，只能先完成幅度校准，并把“多谐波 Upp 全相位板测”列为是否
允许省略相位表的决策门。不能在没有证据时宣称幅度表足够。

### 6.5 表示和插值

推荐保存：

```text
frequency_hz, log_magnitude, unwrapped_phase_residual
```

先从相位中拟合并移除最佳线性时延，再对剩余相位展开，可降低跨节点跳变和插值难度。
运行时对对数幅度和展开相位做分段线性插值；需要完整 `H(f)` 时再恢复线性时延。
若只计算形状、`Upp` 和 RMS，公共线性时延可以忽略。
只在已校准的 10--500 kHz 范围内插值，不对表外频率外推。

查表的唯一权威源应是带原始记录的 CSV/表格，再由脚本生成只读 C 表。禁止人工在
多个头文件中重复抄系数。每张表要绑定前端版本、终接方式和构建哈希；模拟电路、
滤波器、增益、ADC 参考或 FIR 任一变化后，旧表立即失效。

### 6.6 查表验收不能只测节点

校准点只用于拟合。必须另留以下频率作为 holdout，例如：

```text
30.5, 75.5, 150.5, 250.5, 350.5, 425.5, 475.5 kHz
```

并在不同幅度和相位下验证。若只在查表点上得到好结果，不能证明插值有效。

## 7. 分层测试计划

### 7.1 第 1 层：独立双精度参考

建立与板上 C 独立的 Python/NumPy 双精度参考。参考模型负责产生真值和比较，不复用
C 代码中的候选、阈值和求解器，避免“实现和测试犯同一个错误”。固定随机种子并保存
失败向量，确保每次回归可复现。

每个用例至少比较：

- 谐波根数和阶次；
- 基频；
- 各分量峰值和相对相位；
- `Upp`、`Urms`；
- SSE/NRMSE、BIC 和最终质量状态；
- 单帧运行时间。

### 7.2 第 2 层：主机 C 算法回归

当前 host test 只调用算法内部 4 个用例，覆盖不足。扩展为表驱动和确定性随机测试：

| 维度 | 必测集合 |
| --- | --- |
| 基频 | 10 kHz、500 kHz边界可行组合、低/中/高代表点 |
| bin 偏移 | 题设 500 Hz 栅格对应的 `0、+/-0.2、+/-0.4 bin` |
| 额外失谐 | 围绕 500 Hz 栅格 `+/-50、+/-100 Hz`，作为时钟/信号源鲁棒性测试 |
| 根数 | 2 根、3 根 |
| 阶次 | `{1,2}`、`{1,3}`、`{1,2,3}`、`{1,3,4}`、高而不连续的合法阶次 |
| 幅值 | H1 最弱、最高次最弱、等幅、接近总 Upp 上限、`5 mVpeak` 弱线 |
| 相位 | 同相、正交、近峰值抵消、近峰值叠加、确定性随机相位 |
| 数据质量 | 12 bit 量化、直流、白噪声、实测有色噪声、单点毛刺 |
| 模型污染 | 带内非谐波杂散、缺少基波、4 根线、错误谐波关系 |
| 链路 | 模拟复频响、FIR、采样率偏差、幅度相关增益 |

生成测试信号时必须同时满足题目约束：合成总 `Upp` 在指定范围，且每根分量峰值
`>=5 mV`。不能简单把每根线都设置成 50--250 mVpp。

### 7.3 第 3 层：真实 DMA 帧回放

建立原始帧台账。每条记录至少包含：

```text
input settings and load mode
actual wiring
raw 8192-byte analysis frame
FIFO/DMA status before and after
bit/XSA/ELF SHA-256
UART log
expected result or reference instrument result
```

同一 raw frame 必须能在主机回放和板上得到一致结果。这样算法修改不必每次都依赖
现场信号源，也能区分“算法回归”和“硬件链变化”。

### 7.4 第 4 层：完整硬件链保留测试

至少覆盖：

- 50/100/200/250 mVpp 总输入；
- 10--500 kHz 代表点和查表节点之间的保留点；
- 2/3 根线、不同阶次、基波不是最大线；
- 5 mVpeak 弱线；
- 会显著改变合成 `Upp` 的不同相对相位；
- 每个条件至少重复 10 帧，记录最大误差、均值和标准差；
- 板测统计同时检查 `|bias| + 3*std <= 5 mV`，且任何超差样本不得标为高置信度；
- 输入短接噪声、温度变化和供电变化；
- 最大组合下放大器、ADC 和 FIR 均不削顶。

### 7.5 第 5 层：第三问干扰和混叠

分开验证两个问题：

1. `1 MHz` 左右、尚未在 ADC 前混叠的干扰，验证模拟低通和 PL FIR 的协同抑制；
2. raw ADC 第一段混叠危险窗口 `4.62006--5.62006 MHz`，验证模拟滤波器没有寄生
   通带，并能把 200 mVpp 干扰压到误差预算内。

若干扰混叠后恰好落到某个有效谐波频率，数字算法无法知道两者各占多少；此时不能
依赖残差或最小二乘“分离”。若混叠到非谐波频率，算法可以用高残差/杂散拒绝本帧，
但这仍不等于完成第三问，因为题目要求恢复并显示 `u_b`。

## 8. 分阶段实施和退出门槛

| 阶段 | 工作 | 交付物 | 进入下一阶段的门槛 |
| --- | --- | --- | --- |
| P0 契约和证据固化 | 闭合 signed/Fs/DMA/FIFO 契约，保存构建哈希和 raw frame | 一份可复现基线包 | 主机回放与板上同帧结果一致 |
| P1 现状基线 | 不改算法，扩展双精度和主机测试矩阵 | 误差热图、失败用例、运行时间 | 明确现有算法真实失败边界 |
| P2 模型可信度 | 保存 SSE，加入 BIC、次优差距、残差和拒绝状态 | 2/3 根识别及无效输入拒绝回归 | 根数/阶次正确，错误模型不被发布 |
| P3 频率细化决策 | 覆盖五种 bin 偏移和小失谐 | 是否需要共同 f0 优化的证据 | 不需要则跳过；需要则一维优化通过 |
| P4 复增益校准 | 测端到端幅相、生成表、做 holdout | 校准数据、生成表、版本信息 | 保留点幅值/RMS/Upp 达内部目标 |
| P5 多帧和硬件门控 | 2--3 帧一致性、削顶/FIFO/DMA拒绝 | 状态机和故障注入结果 | 有效帧稳定，异常帧不发布 |
| P6 整机验收 | 三种工况、HMI、1/3周期、2秒 | 完整测试记录和报告数据 | 全部题目硬指标通过 |

执行原则：某阶段未通过时，只修复暴露出来的根因，不提前堆叠后续功能。

### 8.1 P1 的算法通过门槛

- 正式有效用例的谐波根数和阶次 100% 正确；
- 无噪声、仅量化条件下，各分量幅值、RMS、Upp 误差 `<=2 mV`；
- 加入实测噪声和模型化链路后，目标 `<=3 mV`，硬门限 `<=5 mV`；
- 内部基频误差目标 `<=250 Hz`，硬门限 `<=1 kHz`；
- 错误根数、非谐波、削顶、短帧和高残差输入必须被拒绝；
- Cortex-A9 `-O2` 单帧算法 `<100 ms`。

### 8.2 P4/P6 的整机通过门槛

- 查表节点和独立 holdout 点都通过；
- `Upp`、真 `Urms`、每根分量峰值的绝对误差均 `<=5 mV`；
- 基频绝对误差 `<=1 kHz`；
- 2/3 根正频率线谱的根数、相对位置和高度正确；
- 1/3 个完整周期稳定切换；
- 最大信号加高频干扰时无削顶、混叠假线和错误高置信度结果；
- 从启动测量到屏幕稳定结果 `<2 s`，计时包含采集、重试、计算和 HMI 刷新。

## 9. 预计代码影响范围

实施时优先保持文件数量最少：

- `g26_signal_analysis.c/.h`：SSE/BIC、质量指标、必要时共同 `f0` 细化；
- `g26_measurement_app.c/.h`：帧质量、重采、多帧一致性和状态输出；
- `algorithm_config.h`：只保留经过测试确定的阈值；
- `g26_signal_analysis_host_test.c`：独立、表驱动的回归入口；
- 一个离线参考/校准脚本和一份权威校准数据；
- 仅当复增益表和插值使主算法明显臃肿时，再新增独立 `g26_calibration.c/.h`。

默认不修改 PL。只有 ADC 时序、FIR、TLAST、背压或模拟混叠测试证明现有硬件链无法
满足契约时，才按既有“重新打开 PL”条件处理。

## 10. 关键风险和对应措施

| 风险 | 后果 | 措施 |
| --- | --- | --- |
| 用同一实现生成真值并测试自己 | 假通过 | 独立双精度参考和真实帧回放 |
| 三分量模型总压过二分量 | 假谱线、错误 Upp | BIC、最弱线显著性、次优差距 |
| 只看归一化残差 | 信号强弱改变阈值含义 | 同时看残差 mV、噪声底和多帧稳定性 |
| 只做幅度 LUT | 多谐波相对相位错误 | 测复增益或用全相位 Upp 实验证明可省略 |
| 校准时接法变化 | 固定 2 倍/一半错误 | 固定 50 Ohm/High-Z 口径并随数据记录 |
| 只测 LUT 节点 | 插值误差被隐藏 | 独立 holdout 频点和幅度 |
| ADC 前混叠 | 数字域不可逆 | 扫 4.62006--5.62006 MHz，模拟滤波先验收 |
| 滤波前削顶/互调 | 产生无法校正的带内分量 | 最大组合观察放大器和 raw ADC |
| 相位校准无共同参考 | 相位表无物理意义 | 双通道/VNA/相干多音共同触发 |
| 标称采样率与真实时钟不一致 | 频率和相位慢性偏差 | 实测 Fs，保存于构建/校准元数据 |
| 更新模拟链后继续用旧表 | 系统性幅值误差 | 表绑定硬件版本和哈希，变更即失效 |
| 只计算法耗时 | 误报满足 2 s | 从按键到屏幕稳定端到端计时 |

## 11. 下一轮实际工作清单

按以下顺序开始，不跳步：

1. 固化当前 bit/XSA/ELF 和 G26 C 源码版本，保存 SHA-256；

## 12. 最终完成定义

只有同时满足以下条件，才能称为“算法完成”，而不是“几个巧合测试点结果不错”：

- 题面三种工况的全范围矩阵均有可追溯测试记录；
- 非整 bin、2/3 谐波、弱基波、不同相位和噪声均覆盖；
- 结果来自端到端复增益校正后的同一谐波模型；
- 模型错误、混叠风险、削顶和帧异常不会被高置信度发布；
- 查表节点之外仍满足 5 mV；
- 构建产物、接线、输入设置、raw frame 和日志可复现；
- 从按键到稳定屏幕结果实测小于 2 s。

在这些证据完成前，单音整 bin 截图只保留为 bring-up 记录，不作为算法准确度结论。
