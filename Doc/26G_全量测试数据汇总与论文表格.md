> 汇总日期：2026-07-31  
> 用途：设计报告测试章节、答辩数据表和上场前 PASS/FAIL 审计。  
> 口径：以当前源码、当前 50 Ohm 链路和最新实测为准；历史不同链路只作

## 1. 结论摘要

当前装置在已经完成的工况中满足题目定量指标：

- 频率覆盖 `10..500 kHz`，实测频率误差通常为 `0..3 Hz`；
- 新增零相位全频段矩阵最大 `Upp` 误差约 `1.767 mV`，最大 `Urms`
  误差约 `0.500 mV`；
- 总 `Upp` 约 `52.8..246.4 mV` 的新增幅度矩阵中，最大 `Upp` 误差约
  `1.286 mV`，最大 `Urms` 误差约 `0.351 mV`；
- 已测 `5 mVpeak` 弱分量组合的最大 `Upp` 误差约 `0.833 mV`，最大
  `Urms` 误差约 `0.261 mV`；
- 已测三分量组合最大 `Upp` 误差约 `1.321 mV`，最大 `Urms` 误差约
  `0.244 mV`；
- 加法器叠加高频干扰后，`4.620060..5.620060 MHz` 的 11 个 raw ADC
  精确折叠点均稳定识别为 2 个有效分量；最大分量幅值误差
  `0.412 mV`、最大 `Upp` 误差 `0.384 mV`、最大 `Urms` 误差
  `0.085 mV`、最慢端到端显示 `520 ms`；
- 当前已测数值均优于题目 `5 mV / 1 kHz / 2 s` 的限制。

上述结论只代表已测且测试激励有效的范围。要在论文或答辩中宣称“全部
指标完成”，仍需关闭第 12 节列出的少量验收缺口。

## 2. 题目指标与统一口径

| 指标 | 题目要求 | 当前判定口径 |
| --- | ---: | --- |
| 合成波 `Upp` | 绝对误差 `<=5 mV` | 与理论合成值或板端示波器值比较 |
| 真 `Urms` | 绝对误差 `<=5 mV` | `sqrt(sum(Ak^2/2))` |
| 各频谱分量幅值 | 绝对误差 `<=5 mV` | UART `amplitude` 为 `mVpeak` |
| 基频 | 绝对误差 `<=1 kHz` | UART `fundamental` |
| 频率分辨率 | `<=500 Hz` | `Fs/N=416.672 Hz` |
| 响应时间 | `<=2 s` | HMI 请求到显示完成 |
| 频谱根数 | 2 或 3 根 | 必须与有效输入分量数一致 |

统一硬件链路：

```text
信号源 50 Ohm 模式
 -> 板端 50 Ohm 终端
 -> 约五阶模拟低通
 -> AD9226，raw Fs=5.120060 MHz
 -> 39 taps FIR /3
 -> Fs=1.7066867 MHz
 -> 4096 x signed16
 -> SG S2MM DMA
 -> PS FFT 候选 + 时域联合最小二乘
```

当前端到端比例为 `2.3096181 mV/code`。幅值和相位校准节点见
[26G 当前架构与实测状态](26G_当前架构与实测状态.md)。

## 7. 不同输入相位与 DG2052 归一化现象

测试信号为 `100/200 kHz`，界面设置 H1=`100 mVpp`、H2=`50 mVpp`。
DG2052 在非零相位下会根据合成波形进行幅度归一化和偏置调整，因此不能
把界面幅值直接当作实际分量幅值。算法结果应与板端示波器比较。

| H2 设置相位 | 算法 H1/H2 mVpeak | 校正后 delta2 | 算法 Upp mV | 示波器 Upp mV | 差值 mV | 结论 |
| ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 0 deg | 50.266 / 25.291 | +1.60 deg | 130.863 | 未记录 | - | 分量幅值准确 |
| 90 deg | 33.321 / 16.736 | +91.0 deg | 75.353 | 76.0 | -0.647 | PASS |
| 180 deg | 50.272 / 25.218 | 约 -179.12 deg | 130.752 | 未记录 | - | 分量幅值准确 |
| 270 deg | 66.662 / 33.366 | 约 -88.6 deg | 150.756 | 152.6 | -1.844 | PASS |

结论：相对相位恢复正确，90/270 deg 下算法 `Upp` 与示波器差值均小于
`2 mV`。该结果支持任意相位下的模型重建能力，但 DG2052 的相位相关
归一化使本组不适合直接验证“界面标称分量幅值不随相位变化”。

## 10. DMA、HMI 与响应时间

- 正式分析帧均通过 `8192 byte` 检查；
- `ALIGN complete: discarded=8168 bytes` 是对齐时丢弃到 TLAST 的部分帧，
  不是正式帧短帧；
- 新 J21--J31 中 `compute_ms=350..430 ms`；
- 1 周期波形发送 `601 points`，`display_tx_ms=90..100 ms`；
- 请求到显示完成 `440..520 ms`，最慢仍比 `2 s` 限制快 `1.48 s`；
- 未见 DMA `interr/slverr/decerr`，未见正式帧采集失败；
- 当前日志已证明参数计算和波形页时序，最终参数页、正频率线谱页、
  1/3 周期切换和完整屏幕验收由 HMI 测试单独关闭。

## 12. 是否可以认为全部指标通过

分两种口径：

1. **核心电测与算法指标：可以近似认为通过。** 已测频率、幅值、
   `Upp`、`Urms`、2/3 分量模型、普通干扰、第一危险窗口和响应时间均
   明显优于题目限制，当前没有发现会使定量指标超过 `5 mV` 的工况。
2. **题目全部评分项和全工况验收：尚不能严格写成全部通过。** 仍缺
   高阶 Arb 有效信号、`5 mVpeak` 完整谱线日志、精确折叠到 250 kHz、
   最大输入叠加干扰不削顶，以及最终 HMI 全页面验收。

论文现阶段建议使用以下表述：

> 在已覆盖的全频段、幅度边界、弱分量、二/三分量、不同相位和高频干扰
> 工况下，装置的频率、电压分量、真有效值、峰峰值和响应时间均满足题目
> 指标。第一 raw ADC 危险窗口 11 个精确折叠点未观察到有效参数超差，
> 表明当前模拟低通与数字 FIR 级联方案具有良好的抗干扰能力。

在第 13 节项目关闭前，不建议写“所有可能输入和全部评分项均已完成验收”。

## 14. 后续优化建议

- 当前最大新增误差约 `1.8 mV`，不需要为了通过指标更换 ADC、增加 FFT

- 若希望把论文数据进一步压到 `1 mV` 级，可用 F06--F08 的完整 H1/H2
  分量日志决定是否补充 `300/350/400 kHz` 幅值节点；不能只用总 `Upp`
  反推单频校准；
- 完成 `5 mVpeak` 完整谱线统计和无干扰 H3/H4 基线后，再决定是否给
  非基波分量增加有效门限；
- 只有当误差离群与 residual、BIC、FIFO 告警相关时，才增加条件复测；
  当前重复数据离散度很小，无条件多帧平均收益有限；
- 已经在 ADC 处混叠到有效频率的干扰不能由 PS 算法恢复，危险窗口仍应
  以模拟抗混叠和板端实测作为最终依据。
