# 2026 G 题当前方案、近期测试与冻结决策日志

> 最后更新：2026-07-29 CST  
> 本文是 26G 当前方案的权威记录。已删除被实测或现有工程推翻的旧方案，
> 包括 `2.048 MHz` 采样、`650 kHz` 模拟截止频率、DMA 接 DDC 输出、
> 未实现 FIR 等历史判断。题目原文见 [26G.md](26G.md)。

## 1. 当前结论

当前推荐链路固定为：

```text
信号源 50 Ohm
 -> 5 阶无源 LC 低通，输出端 51 Ohm 并联到地
 -> 约 30 倍放大器
 -> 约 51 Ohm 源端串联匹配
 -> 50 Ohm / 10 Vpp / 12 bit AD9226 模块
 -> PL: 5.12006 MSPS ADC -> 39 taps FIR /3 -> 4096 点 AXIS 帧 -> DMA
 -> PS: 连续采集、校准、FFT/拟合、参数计算和显示
```

冻结判断：

| 部分 | 当前判断 |
| --- | --- |
| ADC | 不更换。12 bit 在当前有效增益下足以支持 5 mV 绝对误差。 |
| 模拟滤波器 | 暂不更换。实测接近五阶、`fc` 约 680--700 kHz，但必须复测 500 kHz 并验证混叠窗口。 |
| ADC 采样率 | 保持约 `5.12006 MHz`，不切换 65 MHz。 |
| PL FIR 主链 | 功能上冻结，不再为 26G 增加新结构或更改采样率、抽取率、帧长。 |
| PS | 当前主要开发对象。必须完成数据契约修正、连续采集、幅相校准、测量算法和显示。 |

“PL 冻结”不是“PL 已完成全部验收”。只有在第 7 节列出的重新打开条件出现时，
才修改 PL RTL/IP；ADC 输入时序约束和最终板级验证仍需完成。

## 2. 固定数字硬件契约

当前已综合并写入 bitstream 的 26G 主链为：

```text
AD9226 offset-binary 12 bit
 -> ADC/FIFO CDC
 -> 转为 centered signed 16 bit
 -> 39 taps 低通 FIR，decimation=3
 -> Q17 对称舍入和 signed 16 bit 输出
 -> 每 4096 个 FIR 输出样本产生 TLAST
 -> AXIS FIFO
 -> SG S2MM DMA，8192 bytes/frame
```

固定参数：

```text
ADC Fs nominal     = 5,120,060 Hz
ADC Fs implemented = about 5,120,056.5 Hz
FIR decimation     = 3
FIR output Fs      = 1,706,686.667 Hz nominal
frame samples      = 4096 signed int16 samples
frame bytes        = 8192
FFT bin spacing    = 416.67155 Hz nominal
output Nyquist     = 853.34333 kHz
frame duration     = about 2.400 ms
```

FIR 实测/生成指标：

```text
taps                = 39
coefficient bits    = signed 18 bit integer, sum = 2^17
500 kHz             = -0.008071 dB
1 MHz               = -67.630308 dB
worst stopband      = -67.149421 dB from 1 MHz to raw Nyquist
```

依据：

- [top.v](../25G_PL/25G_PL.srcs/sources_1/new/top.v)
- [adc_fir_axis.v](../25G_PL/25G_PL.srcs/sources_1/new/adc_fir_axis.v)
- [fir_compiler_0.xci](../25G_PL/25G_PL.srcs/sources_1/ip/fir_compiler_0/fir_compiler_0.xci)
- [fir_26g_decim3_q17.coe](../25G_PL/script/fir_26g_decim3_q17.coe)

## 3. 近期测试记录

### 3.1 无源 LC 滤波器

测试接法：

```text
信号发生器，设置为 50 Ohm
 -> 5 阶无源 LC 低通
 -> 滤波器输出端并联 51 Ohm 到地
 -> 示波器高阻输入，并联观察 51 Ohm 负载上的电压
```

信号发生器设置为 `200 mVpp`。用户报告的全部频点如下：

> 用户原文“200khz 193khz”按相邻数据的表达方式解释为
> “200 kHz 输入时输出 193 mVpp”；若原意不同，应以复测值覆盖本表。

| 频率 | 输出幅度 | 幅度比 | 衰减 |
| ---: | ---: | ---: | ---: |
| 50 kHz | 197--201 mVpp | 约 0.985--1.005 | 约 0 dB |
| 100 kHz | 197--201 mVpp | 约 0.985--1.005 | 约 0 dB |
| 200 kHz | 193 mVpp | 0.965 | -0.31 dB |
| 500 kHz，较早一次测试 | 177 mVpp | 0.885 | -1.06 dB |
| 750 kHz | 105 mVpp | 0.525 | -5.60 dB |
| 800 kHz | 86 mVpp | 0.430 | -7.33 dB |
| 1 MHz，较早一次测试 | 33 mVpp | 0.165 | -15.65 dB |

将全部新测点约束为五阶 Butterworth 形式：

```text
H(f) = K / sqrt(1 + (f/fc)^10)
```

最小二乘近似得到：

```text
low-frequency gain K ~= 0.984
relative -3 dB cutoff fc ~= 689 kHz
reasonable cutoff interval ~= 680--700 kHz
```

该拟合对 50、100、200、750、800 kHz 和 1 MHz 测点的幅度误差约在
`4 mVpp` 内，说明滤波器总体仍接近五阶低通，不需要立即更换。

但较早记录的 `500 kHz -> 177 mVpp` 与新曲线不一致。上述五阶拟合预计
`500 kHz` 输出约 `193 mVpp`。若 `177 mVpp` 在同一接法下可重复，说明存在：

- 500 kHz 附近局部凹陷或寄生效应；
- 某次测试的 50 Ohm/High-Z 设置不同；
- 探头位置、负载或记录错误。

因此必须使用同一接法复测：

```text
300, 400, 450, 500, 550, 600, 650, 700 kHz
```

在 500 kHz 复测完成前，不把 `177 mVpp` 或 `193 mVpp` 任一数值写死为
最终校准系数。

### 3.2 放大器独立测试

用户报告的放大器幅度：

| 输入 | 高阻测得输出 | 增益 |
| ---: | ---: | ---: |
| 100 mVpp | 3.02 Vpp | 30.20 |
| 200 mVpp | 5.99 Vpp | 29.95 |
| 240 mVpp | 7.12 Vpp，按上下文解释 | 29.67 |
| 250 mVpp | 7.44 Vpp | 29.76 |

`240 mV -> 7.12 V` 是根据其余三组线性数据做出的单位解释。如果原始数据
确实是 `240 mV -> 712 mV`，则该点表示严重异常，必须在继续校准前复测。

四组增益平均约 `29.89`，最大到最小跨度约 `1.78%`。放大器没有明显削顶，
但只用一个理想“30 倍”常数不足以独占全部 5 mV 误差预算；最终使用端到端
两点幅度校准吸收增益偏差和轻微幅度相关误差。

用户还报告断电或万用表条件下 `OUT-GND` 电阻约 `500 Ohm`。该读数不是
运放上电工作时的动态 Thevenin 输出阻抗，不能用于计算 50 Ohm 传输分压。

### 3.3 放大器到 ADC 的 50 Ohm 分压验证

测试接法：

```text
信号发生器，设置为 50 Ohm
 -> 放大器
 -> ADC 需要的 50 Ohm 匹配网络
 -> 10 Vpp、12 bit AD9226
```

`User/test` 板测日志的稳定结果：

| 标称输入 | 稳定 code pp | mean | RMS code | 过零频率 |
| ---: | ---: | ---: | ---: | ---: |
| 100 mVpp / 500 kHz | 约 612--613 | 约 -31 | 214 | 499.589--500.006 kHz |
| 250 mVpp / 500 kHz | 约 1518--1522 | 约 -30~-31 | 535--536 | 499.589--500.006 kHz |

偶发首帧/单点结果：

- 100 mVpp 档出现过 `pp=623`、`pp=619`，但 `RMS=214` 不变；
- 250 mVpp 档出现过 `pp=1563`，但 `RMS=536` 不变。

这表明纯正弦稳态幅度和频率是稳定的，异常主要来自单点极值；最终测量不能
使用原始 `max-min` 作为幅值结论，应使用正交投影/最小二乘拟合。

二分压的定量闭环：

```text
100 mV case:
ADC voltage from code = 612 / 4096 * 10 V = 1.494 Vpp
source resistance inferred from 3.02 V open/high-Z output and 50 Ohm load
                    ~= 51.1 Ohm

250 mV case:
ADC voltage from code = 1520 / 4096 * 10 V = 3.711 Vpp
source resistance inferred from 7.44 V open/high-Z output and 50 Ohm load
                    ~= 50.2 Ohm
```

两组独立结果都得到约 `50--51 Ohm`，与正确的源端串联匹配加 ADC 50 Ohm
终端完全一致。此前“数字幅度少一半”不是 ADC 或 FIR 故障，而是正常的
50 Ohm 源/负载二分压：

```text
effective end-to-end voltage gain
~= amplifier gain * 50 / (51 + 50)
~= 29.89 * 50 / 101
~= 14.80
```

对应输入端的理想码值比例：

```text
input-referred scale ~= 10,000 mV / 4096 / 14.80
                     ~= 0.165 mV/code
5 mV                ~= 30.3 codes
50 mVpp input       ~= 303 codes pp
250 mVpp input      ~= 1515 codes pp
```

实测与上述计算一致，所以目前没有更换 ADC 的依据。

## 4. 5 mV 精度可行性与校准要求

题目要求是绝对误差 `<= 5 mV`：

```text
50 mVpp input  -> 10% relative allowance
250 mVpp input -> 2% relative allowance
```

12 bit ADC 量化并不是主要限制。当前约 `0.165 mV/code`，5 mV 有约 30 code
裕量。真正的误差来源依次是：

1. 模拟滤波器在 10--500 kHz 的幅度和相位响应；
2. 放大器增益误差、输出摆幅和幅度相关压缩；
3. 51/50 Ohm 电阻公差和信号源负载模式；
4. ADC 零点、参考增益、INL 和噪声；
5. 非整 FFT bin、窗函数和直接 `max-min` 算法误差；
6. 多谐波经过模拟滤波器后产生的相对相位变化。

若只在低频做一次固定增益校准，当前五阶拟合在 500 kHz 相对通带平台约低
`1.97%`，对 250 mVpp 输入已相当于约 `4.9 mV`，没有剩余误差预算。因此
必须做频率相关校准。

推荐的端到端校准对象不是单独的 ADC、放大器或滤波器，而是：

```text
BNC input mV
 -> 完整模拟链
 -> FIR signed code amplitude and phase
```

建议至少记录：

```text
frequency: 10, 50, 100, 200, 300, 400, 450, 500 kHz
amplitude: 100 mVpp and 250 mVpp
fields: code amplitude, phase, DC offset, repeated-frame standard deviation
```

400--500 kHz 可根据复测曲线增加频点。PS 对频率和幅度做插值，得到完整链路
的复增益修正。

最终计算原则：

- 频谱幅值：使用拟合得到的每个正弦分量幅度，再除以对应频率的实测增益；
- 真有效值：使用校准后的各正交谐波分量计算，或对重建输入波形计算 RMS；
- `Upp`：校正各分量幅度和相位后重建高分辨率输入波形，再求峰峰值；
- 不使用原始抽取样本的 `max-min` 作为最终 `Upp`；
- 输入短接时测量输入折算噪声，目标 RMS 最好小于约 `1 mV`；
- 最大有用信号叠加 1 MHz 干扰时，直接观察放大器输出与 ADC 原始码，确认无削顶。

## 5. 模拟滤波器与混叠验收

现有滤波器可以继续使用的理由：

- 低频至 200 kHz 衰减较小；
- 750 kHz、800 kHz 和 1 MHz 呈连续下降趋势；
- 1 MHz、200 mVpp 干扰已降为约 33 mVpp；
- 当前数字 FIR 在 1 MHz 再衰减约 67.63 dB，折算回滤波器输入只剩约
  `0.014 mVpp`；
- ADC 和 FIR 板测没有显示非线性或数值溢出。

但是数字 FIR 无法消除在 ADC 采样时已经折叠进 0--500 kHz 的模拟频率。
当前第一段必须由模拟滤波器处理的窗口为：

```text
Fs_ADC - 500 kHz .. Fs_ADC + 500 kHz
= 4.62006 .. 5.62006 MHz
```

必须在保持 51 Ohm 并联负载的实际接法下扫测该窗口，确认：

- 没有 LC 寄生谐振或异常峰化；
- 对 200 mVpp 干扰的实测抑制至少约 40 dB，给 32.04 dB 理论需求留余量；
- 放大器在残余高频干扰下不削顶或振荡。

只有出现以下任一情况才更换或重做滤波器：

1. 500 kHz 的 177 mVpp 异常可稳定复现，且无法通过固定负载和校准解释；
2. 10--500 kHz 响应随接法、温度或幅度明显漂移；
3. 4.62006--5.62006 MHz 出现寄生通带或抑制不足约 40 dB；
4. 相位响应不稳定，导致多谐波 `Upp` 无法校准到 5 mV 内。

## 6. PL 冻结范围

当前 26G 功能不再修改以下 PL 内容：

- ADC nominal sample rate `5.12006 MHz`；
- ADC/FIFO CDC 主结构；
- FIR 39 taps 系数和 `/3` 抽取；
- signed 16 bit FIR 输出格式；
- 4096 samples / 8192 bytes DMA 帧；
- FIR 输出到 AXIS FIFO、SG S2MM DMA 的拓扑。

冻结依据：

- FIR COE、生成 MIF 和 XCI 参数一致；
- FIR 500 kHz 通带和 1 MHz 阻带满足数字处理目标；
- `/3` 后 4096 点的 bin 间隔为约 416.67 Hz；
- 实际 bitstream 已综合实现，内部时序收敛；
- 板测在 500 kHz 得到正确频率、正弦 RMS 关系和线性幅度比例；
- 100 mVpp 与 250 mVpp 测试能够闭合 50 Ohm 二分压计算。

以下事项是 PL/板级验收欠账，但不要求现在重构主链：

1. ADC 12 位输入目前缺少基于器件 `tCO` 和板级走线的 `set_input_delay`；
2. 现有活动 testbench 没有覆盖外层 `adc_fir_axis` 的完整抽取、负数舍入、
   输出背压和 FIR 后 TLAST；
3. FIFO monitor 当前观察 FIR 前 raw AXIS，不代表 DMA/FIR 输出帧统计；
4. DMA 不持续接收时会反压并最终阻断 ADC FIFO 写入，PS 必须避免把发生过
   满溢或停顿的样本当作等间隔数据。

## 7. 重新打开 PL 的条件

只有下列情况出现时才恢复 PL RTL/IP 修改：

1. ADC 输入时序板测失败，必须修改采样相位、IOB 或约束；
2. FIR 专项仿真或板测发现抽取、舍入、饱和、TLAST 或背压错误；
3. PS 使用连续 DMA 和正确对齐后仍稳定出现 FIFO 满溢或丢样；
4. 最终算法明确需要一条当前 DMA 契约无法提供的新硬件数据流；
5. 模拟混叠测试失败，并且确认只能通过改变采样率解决。

不要因为软件尚未完成而先改动 PL。尤其不把 ADC 直接切到 65 MHz：当前 FIR
配置只能持续接收约 5.263 MSPS；65 MSPS 需要新的多级 `/32` 抽取、数百 taps
等效滤波、ADC 输入时序和 DMA/FFT 契约，是整条链重设计，不是参数调整。

## 8. PS 当前必须完成的工作

从现在开始，默认开发重心在 PS，但不是无条件“只改 PS”。按以下顺序推进：

1. **修正数据契约**
   - FIR DMA 样本是 `signed int16`，不能再按旧 raw ADC `u16 >> 4` 解码；
   - 区分 raw ADC `5.12006 MHz` 与 FIR output `5.12006/3 MHz`；
   - FFT、bin 到 Hz、正交投影和帧元数据使用 FIR output Fs。

2. **保证连续、等间隔采集**
   - 使用持续在途的 SG DMA buffer/ring，或在正式测量前充分排空并检查满溢；
   - 发生 FIFO `prog_full/full`、DMA 停顿或短帧时拒绝该帧；
   - 不把只对齐一个 TLAST 等同于已经得到新鲜、连续样本。

3. **建立端到端校准**
   - 保存频率、幅度、复增益和零点表；
   - 插值补偿 LC、放大器、51/50 Ohm 匹配、ADC 和 FIR 的总响应；
   - 用至少两个输入幅度吸收放大器约 1.78% 的增益跨度。

4. **实现 G 题测量算法**
   - 4096 点实数 FFT 做候选搜索；
   - 识别基波和 1--2 个整数谐波，不能只取最大谱峰；
   - 以未加窗正交投影/最小二乘估计每个分量的幅相；
   - Hann 只用于搜索/显示时需补 coherent gain；
   - 重建输入波形计算 `Upp`，计算真 `Urms` 和正频率峰值幅度；
   - 基于重建波形生成稳定的 1 周期或 3 周期显示点。

5. **完成应用和显示**
   - 当前 `identification_main.c` 只运行三帧 FIR 板测，不是 G 题应用；
   - 增加按键状态、时域/频域页面和 1/3 周期选择；
   - 发送绘图点和文本，不传整帧位图；
   - 每个功能从启动到稳定显示不超过 2 s。

6. **修正测试判据**
   - 当前 `clip=0` 只检查 signed 16 bit 的 `-32768/32767`，不能证明 12 bit
     ADC 未削顶；
   - 幅值验收优先使用第 2/3 帧拟合或 RMS，不使用受单点毛刺影响的首帧
     `max-min`；
   - 增加 mV、频率、噪声、短帧、FIFO 满溢和响应时间的明确 PASS/FAIL。
