# 23D 调制识别方案与 DDC 实施计划

> 本文是 23D 调制方式识别、参数估计、SG DMA、流式 DDC 和解调输出的唯一实施文档。  
> 输入：2 MHz、100 mVpp，AM/FM/CW/2ASK/2PSK/2FSK。  
> 平台：AD9226 最高 65 MSPS；双路 AD9767 最高 275 MSPS；当前 ADC 工程配置约 5.12006 MSPS。

## 1. 结论

IQ + FFT 是数学起点，但“当前窗口 IQ + 当前 4096 点原始 FFT”不够完成整题。

正确主线是：

> FFT 做粗搜索，连续复基带保留包络和相位时间信息，PS 完成分类、参数估计和符号判决。

实施上新增一个独立 `ddc_stream` IP，与现有窗口 IQ 并行：

```text
                         ┌→ 现有 iq_demodulator
ADC raw / sample_valid ──┤      → 窗口 I_SUM/Q_SUM
                         │
                         └→ 新 ddc_stream
                                → Zero-IF
                                → 抗混叠低通
                                → 固定倍率抽取
                                → 连续 I/Q AXIS
                                → SG DMA
                                → PS 分类和参数估计
```

现有 IQ 继续用于稳定单音幅相和候选频点确认，不修改其接口和行为。

## 2. 为什么当前窗口不够

当前实际配置：

$$
f_s=5.12006\ \text{MSPS},\qquad N=4096
$$

$$
T_{frame}=\frac{4096}{5.12006\times10^6}\approx0.8\ \text{ms}
$$

$$
\Delta f_{bin}=\frac{f_s}{N}\approx1250\ \text{Hz}
$$

题目要求：

- 调制频率误差不超过 50 Hz；
- 最大频偏误差不超过 300 Hz；
- 调制频率最低 1 kHz。

0.8 ms 数据不足一个 1 kHz 周期。增大原始 FFT 会增加缓冲、CPU 和库限制；当前 CMSIS 快速 RFFT 也只支持到 4096 点。

第一版 DDC 抽取到约 160 kSPS 后：

$$
T_{frame}=\frac{4096}{160001.875}\approx25.6\ \text{ms}
$$

$$
\Delta f_{bin}\approx39.1\ \text{Hz}
$$

因此继续使用 4096 点就能获得足够长的基带窗口。

## 3. 当前 IQ IP 的真实能力

现有模块计算：

$$
I_{sum}=\sum x[n]\cos(\omega_cn)
$$

$$
Q_{sum}=\sum x[n]\sin(\omega_cn)
$$

数据流：

```text
4096 个 ADC 样本
 → I/Q 混频
 → 各累加 4096 次
 → 一个 I_SUM、一个 Q_SUM
```

它会丢失窗口内部的时间变化：

- AM/ASK 包络被平均；
- FM/FSK 相位和频率轨迹被平均或相互抵消；
- PSK 正反相符号可能互相抵消；
- 无法输出连续解调波形。

新 IP 不能通过读取 `I_SUM/Q_SUM` 恢复逐点 I/Q，也不能简单包一层“调用”现有 IP。它必须从同一 ADC raw/valid 独立产生连续复基带。

## 4. 第一版冻结规格

### 4.1 采样率策略

AD9226 最高 65 MSPS，但第一版固定使用当前已工作的约 5.12006 MSPS。

采样率变化会同时改变 NCO、滤波器、抽取、DMA 数据率和 FPGA 输入时序。第一版不实现运行时任意采样率，只允许调节 NCO `PINC`。

| 参数 | 第一版 |
| --- | ---: |
| ADC 采样率 | 5,120,060 Hz |
| 标称载波 | 2,000,000 Hz |
| 抽取倍率 | 32 |
| 复基带采样率 | 160,001.875 Hz |
| 复数点数/帧 | 4096 |
| 帧时间 | 约 25.6 ms |
| I/Q 位宽 | signed 16 + signed 16 |

未来若使用 65 MSPS，必须采用多级抽取，例如：

```text
65 MSPS 混频
 → CIC/半带粗抽取
 → 补偿 FIR + 最终抽取
 → 约 160–250 kSPS
```

不能把面向 5.12 MSPS 的单级 FIR 原样用于 65 MSPS。

### 4.2 频带假设

第一版保留约 ±40 kHz 复基带，假设 2FSK 两频点以 2 MHz 为中心、最大频差约 50 kHz。

如果实测信号源把任一 FSK 频点放到 2 MHz ±40 kHz 之外，必须先确认真实范围，再选择：

- 扩大通带并重新生成 FIR；或
- 改为较低抽取倍率。

不能在范围未知时盲目加宽。

## 5. `ddc_stream` IP 架构

```text
ADC 12-bit unsigned
 → 减 2048
 → 延迟 8 拍
 → 2 MHz DDS sin/cos
 → I = x·cos，Q = -x·sin
 → 舍入/饱和为 signed 16 bit
 → I/Q FIR 低通、抽取 32
 → 丢弃启动瞬态
 → I/Q 交错串行化
 → 异步 FIFO
 → 16-bit AXIS
```

### 5.1 顶层接口

ADC 域：

```systemverilog
input logic        clk_adc;
input logic        rst_n;
input logic [11:0] i_adc_raw;
input logic        i_sample_valid;
```

当前 RTL 已确认 `i_sample_valid` 等于 AD9226 注册样本的 `ad_valid`，不受原始 FIFO `prog_full` 限制。原始 FIFO 填满不会让 DDC 断粮。

控制域：标准 AXI4-Lite，运行在现有 100 MHz PS AXI 时钟。

输出域：

```systemverilog
output logic [15:0] m_axis_tdata;
output logic        m_axis_tvalid;
input  logic        m_axis_tready;
output logic        m_axis_tlast;
```

### 5.2 AXIS 数据格式

为了保持当前 DMA 的 16 位 Stream 宽度：

```text
I[0], Q[0], I[1], Q[1], ... I[4095], Q[4095]
```

`TLAST` 位于 `Q[4095]`。

```text
8192 AXIS beats
16384 bytes DMA BTT
4096 complex samples
```

PS：

```c
int16_t iq_buffer[8192];

i = iq_buffer[2U * k];
q = iq_buffer[2U * k + 1U];
```

### 5.3 最小寄存器

| 偏移 | 名称 | 内容 |
| ---: | --- | --- |
| `0x00` | `CTRL` | RUN、RESTART、CLEAR_FAULT |
| `0x04` | `PINC` | 32 位 DDS 相位增量 shadow |
| `0x08` | `STATUS` | running、config busy、FIFO prog_full、overflow |
| `0x0C` | `OUTPUT_COUNT` | 复数点计数 |
| `0x10` | `FRAME_COUNT` | 完整帧计数 |
| `0x14` | `DECIM` | 只读 32 |
| `0x18` | `SAMPLE_RATE_HZ` | 只读 5,120,060 |
| `0x1C` | `BUILD_ID` | IP 版本 |

配置 CDC 复用现有 IQ 已验证的 shadow + commit toggle + settle 模式。

## 6. NCO、对齐和定点格式

复用现有 DDS 规格：

- phase width：32 bit；
- sin/cos：signed 16 bit；
- DDS latency：8 clocks；
- ADC pipeline：8 clocks。

2 MHz 默认相位增量：

$$
PINC=\operatorname{round}
\left(
\frac{2\,000\,000}{5\,120\,060}2^{32}
\right)=1677701939
$$

```text
PINC = 0x63FFB333
```

定点链路：

```text
ADC unsigned 12
 → signed 13
 → × signed Q1.15 LO
 → signed 29-bit product
 → 对称舍入、右移 15
 → 饱和为 signed 16
```

采用：

$$
I=x\cos(\omega_cn),\qquad Q=-x\sin(\omega_cn)
$$

高于 2 MHz 的输入在复基带中产生正向相位旋转。

不要在 PL 加高通去 DC。AM 载波经 Zero-IF 后就在 DC；ADC 中点偏差应在混频前校准或在 PS 中建模。

## 7. 第一版 FIR

使用两个参数相同的 Vivado FIR Compiler：

```text
fir_ddc_i
fir_ddc_q
```

| 参数 | 初始规格 |
| --- | ---: |
| 输入采样率 | 5,120,060 Hz |
| 抽取 | 32 |
| 输出采样率 | 160,001.875 Hz |
| 通带 | 0–40 kHz |
| 通带纹波 | ≤0.1 dB |
| 阻带起点 | 80 kHz |
| 阻带衰减 | ≥60 dB |
| 初始 taps | 513 |
| 系数位宽 | 18 bit |
| 输入/输出 | signed 16 bit |

513 taps 是初始估计，最终以生成后的实际频响为准。I/Q 两路必须同系数、同 valid、同舍入和同延迟。

重启后丢弃前 16 个抽取输出，避免 FIR 零状态瞬态进入正式帧。

## 8. 异步 FIFO 和故障语义

ADC 域写、100 MHz AXIS 域读：

| 参数 | 数值 |
| --- | ---: |
| 数据宽度 | 17 bit：`{TLAST, data[15:0]}` |
| 深度 | 8192 words |
| 容量 | 一整帧交错 I/Q |

每个复数点两拍写入：先 I，后 Q。写 I 前必须保证能写两个 word，禁止半个 I/Q 点。

ADC 不能因 `TREADY` 拉低而暂停，因此 FIFO 到 `prog_full` 时：

1. 不开始写下一对 I/Q；
2. 设置 `overflow_sticky`；
3. 停止 DDC RUN；
4. PS 丢弃当前 DMA 缓冲；
5. 重建描述符后 `RESTART`。

禁止静默丢样后继续拼出“正常长度”的帧。

## 9. 原始 ADC、AXIS Switch 与 SG DMA

在现有 AXIS Data FIFO 前增加 16 位 AXIS Switch：

```text
S00：原始 ADC，4096 beats，8192 bytes
S01：DDC I/Q，8192 beats，16384 bytes
M00：SG DMA S2MM
```

模式切换：

1. 停止 DDC；
2. 停止/复位 DMA；
3. 选择 AXIS 输入；
4. 建立正确 BTT 的 SG 描述符；
5. 启动 DMA；
6. 清 fault；
7. DDC `RESTART` + RUN。

禁止帧中途切换。

DDC 模式下原始 FIFO 因无人消费会进入 `prog_full`。这是预期现象：

- 不用原始 FIFO blocked 判定 DDC 帧；
- 检查 DDC overflow；
- 检查实际 DMA 长度 16384；
- 对比 DDC frame count 和 SG 完成描述符数。

### 9.1 SG 边界

SG 解决缓冲排队和连续搬运，不解决 DDC、滤波和分类。

当前已经完成单帧 SG 迁移：Vivado 启用 SG S2MM，描述符与数据主口均经
HP0 访问 DDR，XSA/BSP 已更新，PS 使用 BD Ring API 和 S2MM 中断，描述符
及数据缓冲按 Cache line 对齐，并在任务上下文检查实际长度、回收 BD。

这一步为了适配现有主程序，每次只允许一个 BD 在途。连续 DDC 仍需至少
8 个 16384 字节缓冲（覆盖约 204.8 ms）、明确 producer/consumer ownership，
并完成连续 10 秒测试；不能把单帧中断通过当成连续采集通过。

## 10. 六种信号的算法

设：

$$
z[n]=I[n]+jQ[n]=A[n]e^{j\phi[n]}
$$

公共特征：

$$
A[n]=\sqrt{I[n]^2+Q[n]^2}
$$

$$
\Delta\phi[n]=\arg(z[n]z^*[n-1])
$$

$$
f_i[n]=\frac{\Delta\phi[n]}{2\pi}f_{s,bb}
$$

### AM

- 包络为 1–5 kHz 正弦；
- 瞬时频率基本稳定；
- 包络 FFT/拟合估计 $F$；
- 调幅系数：

$$
m_a=\frac{A_{max}-A_{min}}{A_{max}+A_{min}}
$$

### FM

- 包络基本稳定；
- 瞬时频率呈正弦变化；
- 相位差恢复 $f_i[n]$；
- 由拟合频率获得 $F$；
- 由频率摆幅获得 $\Delta f_{max}$；
- 计算：

$$
m_f=\frac{\Delta f_{max}}{F}
$$

### CW

- 包络方差低；
- 瞬时频率方差低；
- 没有稳定调制分量；
- 必须另设“无信号”门限。

### 2ASK

- 包络呈高低两簇；
- 载频基本不变；
- 对 6/8/10 kbps 候选做定时度量；
- 自适应阈值判决 0/1。

### 2FSK

- 包络基本稳定；
- 瞬时频率呈两个簇；
- 两个相关器/Goertzel 比较能量；
- 估计 $f_{c0}$、$f_{c1}$ 和 $R_B$；
- 计算：

$$
h=\frac{|f_{c1}-f_{c0}|}{R_B}
$$

### 2PSK

- 包络基本稳定；
- 基带相位出现约 180° 跳变；
- 需要载波频偏校正和相位参考；
- 最小实现使用平方/Costas 思路或分段相位聚类；
- 再按 6/8/10 kbps 做符号定时。

推荐分类顺序：

```text
输入有效？
 ├─ 否：无信号/过载
 └─ 是
     ├─ 包络变化
     │   ├─ 正弦：AM
     │   └─ 两电平：2ASK
     └─ 包络稳定
         ├─ 瞬时频率正弦：FM
         ├─ 瞬时频率两电平：2FSK
         ├─ 相位约 π 跳变：2PSK
         └─ 都没有：CW
```

## 11. 输出方案

### AM/FM 基本部分

消息都是 1–5 kHz 正弦。估计频率后，优先复用现有 DDS 和任一路 AD9767 重建同频正弦。

这是“按估计结果重建”，不是保留输入绝对相位的逐点解调，但改动最小。

### ASK/FSK/PSK

增加最小 BRAM NRZ 播放器：

```text
PS 写入判决 bit
 → PL 按 6/8/10 kbps 读取
 → 0/1 映射高低 DAC 码
 → 单一输出端口
```

第一版不做通用任意波 DAC 播放器。

### 模拟乘法器

两路 DA 分别输出载波和带 DC 的包络，再经模拟乘法器可以产生 AM。单个乘法器不能独立产生 FM；FM 仍需要 NCO/VCO 或完整正交矢量调制路径。

模拟乘法器不参与接收 DDC。

## 13. 仿真和验收用例

### DDC RTL

- 2 MHz CW：I 稳定、Q 接近零；
- ±25/±40 kHz 偏移：相位旋转方向和频率正确；
- AM 1/5 kHz、$m_a=0.3/0.9$：包络正确；
- FM 1/5 kHz、频偏 5/25 kHz：相位差正确；
- FSK ±25 kHz、6/8/10 kbps：频率跳变连续；
- PSK 180° 跳变：跨帧仍可观察；
- 随机 `TREADY`：短阻塞数据连续，长阻塞明确 fault；
- 改 `PINC`：只在 restart 边界生效。

### FIR

- 通带纹波 ≤0.1 dB；
- 80 kHz 起阻带衰减 ≥60 dB；
- I/Q valid 和延迟一致；
- 满幅输入不发生未处理溢出。

### 系统

- 一帧严格 16384 字节；
- `TLAST` 位于最后一个 Q；
- 连续 SG 运行 10 秒无 overflow、短帧和描述符错误；
- DDC frame count 与完成描述符数一致；
- 原始 ADC 模式和旧窗口 IQ 未被破坏；
- AM/FM/CW 和数字调制参数达到题目误差要求。

## 16. 当前单 BD SG DMA 位流的 DDC 上板保真度测试

本节只验证 DDC 是否保留后续解调需要的幅度、频率和相位信息，不实现调制方式识别。
当前 PS 入口运行 `ddc_validation_run()`；每次 PL/外设复位后只采集 1 个帧，每帧仍为
4096 个复数点、8192 个交错 `s16`、16384 字节。

当前 DDC `RESTART` 会清空 IP 内部 XPM FIFO，但不会复位 BD 中位于 DDC 与 DMA 之间的
`axis_data_fifo_0`。首帧 TLAST 后到 PS 写 STOP 之间可能已有下一帧的少量 beat 进入该 FIFO，
因此禁止在同一次 PL/外设复位中循环执行多次 one-frame SG DMA。需要重复统计时，每次都要
先做能够清空 PL 外设和 AXIS FIFO 的完整复位，再重新运行 ELF。

### 16.1 每帧串口指标

- `power min/max/mean`：$I^2+Q^2$ 的最小、最大和平均值；
- `freq min/max/mean`：相邻有效复样本相位差得到的瞬时频率；
- `negative/positive`：超过可配置门限的正负频率均值和点数；
- `phase_max/jumps`：最大相位步进和超过可配置角度的跳变数；
- `sat/zero/fault/dma_error`：饱和复样本、全零复样本、DDC fault 和 DMA error；
- `OUT/FRAME/DMA_LEN`：DDC 复数点数、完整帧数和 DMA 实际长度。

默认只在相邻两点的 $I^2+Q^2\ge4$ 时计算相位和瞬时频率，避免把无信号或
ASK 关断区的未定义相位当作有效频率。`zero` 是诊断量，不是通用失败条件：无信号和
OOK/2ASK 低电平允许出现零样本。`sat`、DDC fault、DMA error 或帧契约错误会直接失败。

### 16.2 操作顺序

1. 保持当前已经验证过的 bitstream，只更新 PS ELF；确认实际编译命令含 `-O2`。
2. 信号发生器载波统一设为 2.000 MHz、100 mVpp；每次只改变表中的调制参数。
3. 等待信号源输出稳定后，重新下载 bitstream/ELF，或执行已确认会复位 PL 外设和
   `axis_data_fifo_0` 的整板复位；仅重新 Run ELF 或只复位 DMA 不算。
4. 保存从 `BUILD` 到最终 `PASS/FAIL` 的完整日志；不能在一次程序运行内连续采多帧。
5. 每个用例先采 1 帧。只有结果靠近判据边界、表现不稳定或幅度裕量可疑时，才额外做
   3 次“完整复位后单帧采集”并比较日志。
6. 完成一个用例后再设置下一个用例。当前程序不控制信号源，也不根据统计值自动声称识别成功。

### 16.3 最小矩阵

| 用例 | 信号源设置 | DDC 保真度观察点 |
| --- | --- | --- |
| AM-1 | $F=1$ kHz，$m_a=0.9$ | 功率随深包络跨越大范围；理想功率最小/最大比约 0.0028，低谷可能受当前量化裕量影响 |
| AM-2 | $F=5$ kHz，$m_a=0.3$ | 功率层次仍清楚；理想功率最小/最大比约 0.29，不应相对 1 kHz 用例被 FIR 明显压扁 |
| FM-1 | $F=1$ kHz，$\Delta f_{max}=1$ kHz | 功率基本稳定；瞬时频率围绕残余 NCO 误差作约 $\pm1$ kHz 摆动 |
| FM-2 | $F=5$ kHz，$\Delta f_{max}=25$ kHz | 功率基本稳定；瞬时频率方向正确，范围接近 $\pm25$ kHz |
| 2ASK-1 | 6 kbps，使用信号源实际 2ASK/OOK 高低电平设置 | 功率应出现明确高低层次，关断区允许 `zero` 增加 |
| 2ASK-2 | 10 kbps，高低电平设置同上 | 高低功率层次仍能保留，不能因码速率提高而合并成单层 |
| 2PSK | 10 kbps，180° 相位翻转 | 功率基本稳定，`phase_max` 接近 180000 mdeg，`jumps` 非零 |
| 2FSK | 10 kbps，$f_{c0}=1.975$ MHz、$f_{c1}=2.025$ MHz | $h=5$ 题目边界；正负频率簇应接近 $-25/+25$ kHz，点数均非零，功率相对中心 CW 不应明显下降 |

> 2ASK 的调制度/高低电平格式依赖具体信号发生器，不能在代码或文档中假造统一值；
> 上板时必须把实际设置随串口日志一起记录。已有 CW、无信号和 $\pm12.8$ kHz 2FSK
> 结果作为回归基线，不要求在本矩阵中重复采集。

### 16.4 公共通过条件

每一帧都必须满足：

- `OUT=4096`、`FRAME=1`、`DMA_LEN=16384`；
- `fault=0`、`dma_error=0`、`sat=0`；
- 需要复测时，独立复位所得帧的功率、频率范围和相位特征可重复；
- AM/ASK 的功率层次符合调制深浅；
- FM/FSK 的瞬时频率符号和范围符合设置；
- 2PSK 存在约 $\pi$ 的相位跳变；
- $\pm25$ kHz 2FSK 的平均功率相对中心 CW 基线没有明显的 FIR 通带衰减。

### 16.5 当前幅度裕量的否决条件

已有 100 mVpp、2 MHz CW 只有约 10 个 DDC 输出码。若 5 kHz、$m_a=0.3$ 的 AM 用例
在独立复测中无法稳定区分功率高低，或其低包络长期与无信号基线不可分，则即使 DMA、fault
和频率指标全部通过，也只能说明 DDC 数据链路正确，不能说明幅度类识别裕量足够。此时先测
模拟前端总增益、ADC 中点和 DDC 定点增益，再决定是否调整模拟增益或定点缩放。
