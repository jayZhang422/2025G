## 当前最重要的判断

- 当前工程实际 ADC 配置约为 5.12006 MSPS；AD9226 器件上限 65 MSPS 不是第一版默认运行速率。
- 第一版 DDC 固定 32 倍抽取到约 160 kSPS，4096 个复数点约为 25.6 ms。
- 现有 IQ IP 是窗口相关积分器，只输出一组 `I_SUM/Q_SUM`，不能替代连续 I/Q 流。
- 新 DDC 与现有 IQ 并行，不能通过读取现有 IQ 的累加结果恢复逐点基带。
- SG DMA 解决连续缓冲和排队，不负责 Zero-IF、滤波、分类或输出。
- 双路 AD9767 最高 275 MSPS，基本部分可复用 DDS 输出 1–5 kHz 正弦；数字部分增加最小 BRAM NRZ 播放器。
- 外接模拟乘法器可以产生 AM，但单个乘法器不能独立产生 FM。
