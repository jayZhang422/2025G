# PS 信号分析算法

## 输入与输出

输入是一帧 4096 个 16 位 DMA 样本。有效 ADC 码位于高 12 位，算法先右移 4 位取得原始码值。输出 `signal_analysis_result_t` 包含频率从低到高排列的 A/B 分量、每个分量的基波幅度和相位、波形类型，以及联合模型的归一化残差。

## 算法流程

1. `signal_prepare_adc_frame` 去除均值，并将 Hann 窗数据送入 4096 点 CMSIS 实数 FFT。
2. `signal_compute_magnitudes` 得到半谱模值；`signal_find_candidate_peaks` 在调用者 profile 指定的频带寻找局部峰值。
3. `signal_refine_frequency` 用三点抛物线插值细化 FFT bin。`signal_snap_to_grid` 只保留满足 profile 频率栅格和算法默认容差的候选。
4. `signal_build_frequency_candidates` 额外加入三倍频/三分频候选，处理三角波三次谐波与另一分量基波重合的情况。
5. 枚举两个频率候选及 A/B 的四种正弦/三角组合。对每个组合，先作正交投影得到基波幅相，再用两轮交替残差投影分离互相干扰。
6. `signal_joint_residual` 以重建信号与采样信号的归一化均方根误差评分，取残差最小的组合。

三角波模型仅合成奇次谐波，幅值按 `1/n^2` 衰减并交替反相，最高使用 `APP_TRI_MAX_HARMONIC`。振荡器采用递推而非逐点 `sinf/cosf`，每 64 点归一化一次，降低运算量和累计误差。

## 锁定策略

`signal_separator_app.c` 中的 `app_normalize_lock_measurement` 拒绝残差过大的结果、将频率吸附到当前 profile 的频率栅格并验证上下限。随后需要连续 `profile->confirm_frames` 帧得到相同 A/B 波形和频率，才允许启动 DDS；锁定超时仍为算法默认值 `APP_LOCK_TIMEOUT_SECONDS`。锁定后不再跟踪输入频率，避免噪声影响输出。`PROFILE_OLD_SEPARATOR` 的所有相关值与拆分前一致。

## 自测

`signal_run_self_tests` 构造合成帧，覆盖四种波形组合以及 `fB = 3*fA` 的谐波冲突。它只验证当前 C 算法，不验证 DMA、RTL 或板级模拟链路。
