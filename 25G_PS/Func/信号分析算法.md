# 2026 G 周期信号分析算法

## 输入与输出

算法输入固定为一帧 4096 个滤波后 `s16` 样点：

```text
N  = 4096
Fs = 5120060 / 3 Hz = 1706686.666... Hz
```

题目信号包含 2 个或 3 个正弦分量。基波频率位于 500 Hz 栅格，其余分量是基波的整数倍。分量幅度以峰值 mV 表示；Upp 表示拟合后总波形的峰峰值，不是各分量幅度的简单相加。

## 活动算法

1. 将 `s16` 样点转换为浮点并处理直流项。
2. 加 Hann 窗后调用 CMSIS-DSP 4096 点 RFFT，得到稳健的频谱候选。
3. 在题目允许范围内按 500 Hz 基波栅格评估整数谐波族，选择能同时解释 2 个或 3 个谱线的候选。
4. 对选中频率一次性建立联合时域模型：

```text
x[n] = dc + sum(ak * cos(2*pi*hk*f0*n/Fs)
                + bk * sin(2*pi*hk*f0*n/Fs))
```

5. 联合求解全部 `ak`、`bk`，再换算每个分量的峰值幅度与相位。联合拟合避免逐条扣除造成的泄漏误差累积。
6. 根据模型计算 RMS 和归一化残差；在一个完整基波周期内高密度重构模型，以 `max(model) - min(model)` 计算 Upp。

Upp 必须来自高密度模型，而不能只取原始采样点的最大值和最小值。后者在采样与信号相位恰好构成稀疏相位网格时会系统性低估峰峰值。

## FFT 与 IQ 的边界

- 使用 FFT：RFFT 只负责快速找到和比较候选谐波族。
- 不使用 IQ/DDC：最终参数来自原始分析带宽内的多频联合时域拟合。
- 不使用 PL DDS 或自定义 FFT：当前题目不需要已知单载波的 IQ 解调，也不需要维护第二套 FFT 实现。

旧 signal separator、DDC/IQ 和 modulation analysis 实现因此降为非活动历史模块。它们不是当前 `main()` 的依赖。

## 队友算法的复用边界

当前方案复用队友实现中已经验证过的 Hann 加窗、FFT 峰搜索和谱峰细化思路，FFT 采用现有 CMSIS-DSP。原始码值解码、PS FIR、Simple DMA、旧 HMI 以及只在采样点上取 Upp 的做法不直接复用，因为它们与当前 PL 数据契约或题目误差目标不一致。

## 幅值标定

初始换算系数为：

```text
APP_G26_INPUT_MV_PER_CODE = 0.1645 mV/code
```

该数值只适用于当前放大链的 bring-up，不是最终精度结论。直连 ADC 板测时应改为约 `2.44140625 mV/code`，不能继续沿用 `0.1645`。模拟低通、可选增益级、ADC、PL FIR 的通带幅相和板间差异都会进入端到端传递函数。最终应使用已知幅值与相位的多频点信号做板级复数标定；在完成前不得把算法输出当作已校准仪表值。

滤波后的 `s16` 帧也不能可靠证明 ADC 前端没有削顶。满量程与弱信号测试仍需结合原始前端余量或后续 PL 原始削顶计数完成。
