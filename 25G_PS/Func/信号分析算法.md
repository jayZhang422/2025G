# 2026 G 周期信号分析算法

## 输入与输出

```text
Fs = 5120060 / 3 = 1706686.667 Hz
N  = 4096
Delta f = Fs / N = 416.672 Hz
输入格式 = signed int16
```

输出为 2 或 3 个整数谐波分量，每个分量包含频率、峰值幅度、相位和谐波
阶次；整体结果包含基频、DC、`Urms`、`Upp`、归一化残差、BIC 和
`delta_bic`。

## 活动算法

1. 用 4096 点均值估计 ADC 中点偏置。
2. 去均值、加 Hann 窗后执行 CMSIS 4096 点 RFFT。
3. 使用局部峰和三点对数插值得到频率候选。
4. 从强候选构造可能的基频，并收集满足整数倍关系的谐波阶次。
5. 对二分量和三分量模型，在未加窗数据上联合拟合 DC、正弦和余弦
   系数。
6. 进行 4 轮、每轮 5 点的基频细化，以残差平方和选择最佳频率。
7. 用 BIC 选择二分量或三分量模型。
8. 基波必须同时满足 `3 sigma` 和 `0.5 mVpeak` 门限。
9. 对每个分量应用端到端幅值和相位校准，再统一计算指标和显示波形。

拟合模型：

```text
x[n] = D + sum(a_k sin(2*pi*f_k*n/Fs)
             + b_k cos(2*pi*f_k*n/Fs)) + e[n]
A_k  = sqrt(a_k^2 + b_k^2)
phi_k = atan2(b_k, a_k)
```

FFT 只负责“在哪里”，联合最小二乘负责“有多大”。这避免了非整周期
采样和谱泄漏直接进入最终幅值。

## Urms、Upp 与相位

各正交分量的峰值为 `A_k` 时：

```text
Urms = sqrt(sum(A_k^2 / 2))
```

ADC 中点偏置不属于题目输入直流，因此不计入 `Urms`。

绝对相位会随异步 DMA 起点变化。当前先扣除输入到 ADC 的展开相位
`theta(f)`，重建时使用：

```text
relative_phase_k = (phi_k - theta(f_k))
                 - harmonic_order_k * (phi_1 - theta(f_1))
```

该量与采样起点无关。算法在一个完整基波周期内生成 4096 个模型点，
`Upp = max(model) - min(model)`。对外显示的 1/3 周期波形各为 640 点。


## 模型误判保护

曾出现 `200/400 kHz` 被解释成 `11.765 kHz` 的 H17/H34，拟合基波仅
`0.106 mVpeak`。原因是高阶谐波假设在残差中找到统计显著但不符合题目
最小幅值的伪基波。当前基波门限复用 `0.5 mV` 候选下限，合法
`5 mVpeak` 分量仍有 10 倍余量；启动自检覆盖 `0.106 mV` 拒绝和
`5 mV` 接受。

## 当前验证

- 10..500 kHz、50 mVpeak：最大分量误差约 0.561 mV。
- 25 mVpeak：最大分量误差约 0.363 mV。
- 两个 25 mVpeak 分量：Urms 最大误差约 0.240 mV。
- 频率误差通常 0..3 Hz。
- 1/1.5/2 MHz、200 mVpp 干扰：最近测试的有效参数相对基准最大变化
  小于 0.2 mV。
- 250/500 kHz 零相位双音：相位补偿前相对相位 `-20.569 deg`、
  `Upp=174.567 mV`；补偿后 `+1.250 deg`、`Upp=175.752 mV`。
- raw ADC 精确危险折叠点 4.720060、5.520060、4.620060、5.620060 MHz：
  有效参数误差均小于 1 mV，额外 H3/H4 为 `0.557..0.732 mVpeak`。
- 启动自检通过，常规测量约 80..340 ms，三分量干扰测试约 570 ms。
