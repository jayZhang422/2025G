# PS 硬件接口与任务流程

## FreeRTOS 入口

`identification_main.c` 创建 `signal_separator_task` 后启动调度器。
`signal_separator_task.c` 只调用 `signal_separator_run` 并处理异常退出；
`signal_separator_app.c` 保存现有信号分离状态机并按原顺序初始化 IQ、DMA、
FFT、按键、FIFO monitor 和 DDS。

```text
main
 `- signal_separator_task
     `- signal_separator_run
         |- DMA + cache + FFT 双分量识别
         |- FIFO monitor 与限频诊断
         |- 已知频点 PL IQ 测量
         `- DDS BRAM 原子提交
```

工程只有 `identification_main.c` 定义 `main()`，不再通过宏改名或
`#include` 包含 `.txt/.c` 源文件。

## DMA 采集

`dma_init_s2mm` 配置 `XPAR_AXI_DMA_ADC_DEVICE_ID` 的 simple-mode S2MM 通道。`dma_capture_frame` 启动一帧传输、轮询完成并在超时或错误时复位恢复通道。调用者只能在成功返回后对接收 DDR 缓冲区执行 `Xil_DCacheInvalidateRange`，然后解析样本。

```c
dma_init_s2mm(&dma, APP_DMA_RX_DEV_ID);
dma_capture_frame(&dma, APP_DMA_RX_DEV_ID, g_adc_raw_buffer,
                  APP_RX_FRAME_BYTES);
Xil_DCacheInvalidateRange((UINTPTR)g_adc_raw_buffer, APP_RX_FRAME_BYTES);
signal_analyze_frame(g_adc_raw_buffer, ..., &result);
```

## DDS/DAC BRAM 协议

`dds_control_from_component` 将分析分量转换为 DDS 步进、相位和幅度配置。`dds_control_commit` 先写完整 A/B 快照和控制字，最后递增写 `COMMIT_SEQ`，使 PL 原子生效。启动时传入 `phase_reload=1, run=1`；停止时传入 `run=0`；运行期间 B 相位微调使用 `dds_control_adjust_b_phase`。

## 按键

按键均为低有效 PS EMIO GPIO。`button_input_take_*_press` 经过延时去抖并等待释放，每次物理按压只返回一次。KEY1/MIO50 开始，N16 复位，T17/R17 分别增加/减少 B 相位 5 度。按键管脚必须沿用 `app_config.h` 的 BSP 宏和定义。

## PL IQ 解调器

`iq_demodulator_measure` 将目标频率按 ADC 实际时钟换算为 32 位 PINC，写入 IQ AXI-Lite shadow 寄存器并提交。随后等待配置应答和结果待处理，读取 48 位有符号 I/Q、样本数与结果 PINC，最后 W1C 确认结果。

```c
iq_demodulator_t iq;
iq_measurement_t result;

iq_demodulator_init(&iq);
if (iq_demodulator_measure(&iq, frequency_hz, &result) == XST_SUCCESS) {
    /* 幅值：sqrt(I*I + Q*Q) / sample_count；相位：atan2(Q, I)。 */
}
```

绝对相位包含 ADC/DAC 时钟、模拟链路和配置时刻造成的固定偏移，板上测试前需要用已知参考做标定。

## 串口诊断

诊断按故障域使用固定前缀：`[APP]` 状态机与按键，`[ADC]` 样本统计，
`[DMA]` S2MM，`[FIFO]` FIFO/AXIS monitor，`[FFT]` 分析与锁定，`[IQ]`
PL IQ 结果，`[DDS]` BRAM 提交快照。此次整理只调整前缀和打印函数归属，
不减少原有诊断字段，也不让日志参与控制流。
