# 2026 G 硬件接口与任务流程

## 活动数据路径

```text
信号源 50 Ohm
 -> 板端滤波器前 50 Ohm 对地终端
 -> 约五阶模拟低通，截止约 800 kHz
 -> AD9226，5.12006 MSPS
 -> H_top raw AXIS
 -> adc_fir_axis：centered signed + 39 taps FIR /3
 -> 4096 x signed16，TLAST=8192 byte
 -> AXIS FIFO -> SG DMA S2MM -> DDR
 -> g26_measurement_task
```

PS 必须按 `s16` 解释 DMA 数据，使用 `5120060 / 3 Hz`，不得执行旧
`u16 >> 4` 解码或额外 PS FIR。

## 模拟前端

当前无模拟放大器。信号源固定为 50 Ohm 模式，板端 50 Ohm 终端焊在
模拟滤波器之前。全局比例和频率校准已经按该链路得到；任何终端、滤波器或
ADC 输入网络变化都会使现有校准失效。

模拟滤波器在 1 MHz 单音测试中约为 `100 mVpp -> 20 mVpp`，即约
14 dB。PL FIR 在 1 MHz 约 67.63 dB，典型级联约 81.6 dB。该相加只
适用于干扰在 ADC 后仍位于 FIR 阻带的情况；`4.62006..5.62006 MHz`
可能先混叠进 0..500 kHz，只能依靠 ADC 前模拟滤波器。

## START/STOP 实时测量状态机

```text
ARMED
  START -> LIVE
LIVE
  -> ALIGN -> discard to TLAST
  -> WARMUP -> discard 3 frames
  -> CAPTURE -> one 8192-byte frame
  -> ANALYZE/CALIBRATE/WAVEFORM
  -> DISPLAY -> queue next generation -> LIVE
  STOP/KEY2 -> clear output/screen/FIFO sticky -> ARMED
```

每个 generation 仍使用现有单帧 SG DMA 和稳定快照，不增加多 BD 环形采集。
generation、staging 和 mutex 保证 HMI 只读取完整结果；有效结果刷新当前页的
波形、Upp/Urms/基频或频谱频率/幅值，无效结果清屏后自动重试。

## DMA 与质量检查

1. DMA 接管缓冲区前 flush cache。
2. 对齐操作提交丢弃 BD，直到帧边界。
3. 每个完成 BD 回收后 invalidate cache。
4. 预热帧和正式帧均要求实际长度为 8192 byte。
5. 正式帧前后读取 FIFO monitor。
6. `blocked_reset` 增长拒绝结果；`blocked_high_watermark` 当前告警。

串口日志保留 DMA 状态、帧长、FIFO 质量、模型残差、BIC 和测量时间，
用于区分采集、校准和模型问题。

## 当前输出与未完成项

已经提供：

- `Upp`、真 `Urms`、基频；
- 2/3 个正频率分量的频率和峰值幅度；
- 1、3 周期各 640 点波形；
- 结果有效标志和完整诊断量。

尚未完成：

- 串口屏实时刷新实板验收；
- 4.62..5.62 MHz 危险混叠窗口、5 mVpeak 和总 Upp 边界的完整验收。

当前实板测量时间约 80..340 ms，1/1.5/2 MHz、200 mVpp 干扰测试已
通过；不能据此宣称所有 `f_j >= 1 MHz` 均已验证。
