# PS 自研函数索引

## 信号处理

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `signal_analyze_frame` | 分析一帧 ADC 数据，识别两路频率、波形、幅相。 | FFT 实例和所有工作区不可为 NULL；DMA 缓冲区应已失效缓存。 |
| `signal_track_result` | 对已锁定结果进行频率一阶平滑。 | 当前锁定主流程不自动调用它更新 DDS。 |
| `signal_run_self_tests` | 执行合成输入回归。 | 适合启动诊断，不替代硬件测试。 |
| `signal_waveform_name` | 返回波形类型字符串。 | 用于日志。 |

## DMA 与 DDS

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `dma_init_s2mm` | 初始化 S2MM DMA 并确保无 SG 模式。 | 使用 `APP_DMA_RX_DEV_ID`。 |
| `dma_capture_frame` | 轮询接收一帧并负责错误恢复。 | 返回成功后再失效缓存。 |
| `dds_control_init` | 设置 BRAM 基址与初始提交序号。 | 每个控制对象启动时调用一次。 |
| `dds_control_from_component` | 将分析结果转换为 DDS 通道配置。 | 相位以度传入。 |
| `dds_control_commit` | 原子提交两通道 DDS 快照。 | 内部保证 `COMMIT_SEQ` 最后写入。 |
| `dds_control_adjust_b_phase` | 在保持频率的同时微调 B 相位。 | 仅在 DDS 已运行时使用。 |

## IQ、按键与诊断

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `iq_demodulator_init` | 绑定 IQ AXI-Lite 基址。 | 需要 BSP 导出的 `XPAR_IQ_DEMODULATOR_0_BASEADDR`。 |
| `iq_demodulator_measure` | 以单频窗口获得 I/Q 累加结果。 | 成功后立即使用结果；驱动已完成 W1C 确认。 |
| `button_input_init` | 初始化四个 EMIO GPIO 输入。 | 失败时不要进入按键主循环。 |
| `button_input_take_*_press` | 消费一次去抖后的按压。 | 函数会等待按键释放。 |
| `diagnostics_*` | 受频率限制的 DMA、分析、DDS 日志。 | 仅用于诊断，不能参与时序决策。 |
