# 2026 G PS 函数索引

以下仅列当前活动测量链路。旧 signal separator、DDC/IQ、DDS 和
modulation analysis 接口均为非活动历史模块。

## 信号分析

文件：`Identification_Processing_System/src/User/include/g26_signal_analysis.h`
和 `User/src/g26_signal_analysis.c`。

| 接口 | 作用 |
| --- | --- |
| `g26_signal_analysis_init` | 初始化 CMSIS 4096 点快速实数 FFT。 |
| `g26_signal_analyze` | 搜索并拟合 2/3 个整数谐波分量，返回幅相、频率、DC 和模型质量。 |
| `g26_signal_apply_amplitude_calibration` | 对每个分量应用当前频率补偿，并重新计算 `Urms/Upp`。 |
| `g26_signal_generate_waveform` | 生成 1 或 3 个完整周期的相对相位模型波形。 |
| `g26_signal_analysis_self_test` | 覆盖合成算法、最小合法基波、伪基波拒绝和校准指标。 |

主要类型：

| 类型 | 内容 |
| --- | --- |
| `g26_signal_component_t` | `frequency_hz`、`amplitude_mv`、`phase_rad`、`harmonic_order` |
| `g26_signal_result_t` | 2/3 个分量、基频、DC、`rms_mv`、`upp_mv`、残差和 BIC |

## 测量任务

文件：`User/include/g26_measurement_app.h` 和
`User/src/g26_measurement_app.c`。

| 接口 | 作用 |
| --- | --- |
| `g26_measurement_task` | KEY1 触发 DMA 对齐、3 帧预热、正式帧分析和结果保持；KEY2 清除重装。 |
| `g26_measurement_output` | 返回只读结果区；`valid=1` 后可读取结果和两组 640 点波形。 |

## 复用驱动

| 接口组 | 当前用途 |
| --- | --- |
| `dma_init_s2mm` / `dma_align_s2mm` / `dma_capture_frame` | SG DMA 初始化、TLAST 对齐和单帧采集 |
| `dma_last_s2mm_length_bytes` | 严格校验正式帧为 8192 byte |
| `fifo_monitor_snapshot` / `fifo_monitor_clear_sticky` | 正式帧前后质量检查 |
| `button_input_take_start_press` / `button_input_take_reset_press` | KEY1/KEY2 去抖事件 |

## 配置契约

| 配置 | 当前值 |
| --- | ---: |
| 分析点数 | 4096 |
| 分析采样率 | `5120060 / 3 Hz` |
| 输入格式 | `signed int16` |
| 帧长度 | 8192 byte |
| 预热帧 | 3 |
| 显示波形点数 | 640 |
| 全局比例 | `2.3096181 mV/code` |

算法启动自检和实板测量当前通过。串口屏任务尚未实现，但所需参数、正频率
分量和 1/3 周期绘图点已经由 `g26_measurement_output_t` 提供。
