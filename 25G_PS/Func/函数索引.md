# PS 自研函数索引

## 应用入口

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `signal_separator_task` | FreeRTOS 任务入口。 | 只管理应用运行和任务退出，不包含业务源文件。 |
| `signal_separator_run` | 运行现有 `ARMED -> LOCKING -> RUNNING` 状态机。 | 保留原有初始化顺序、锁定条件、按键与 DDS 行为。 |

## 信号处理

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `signal_analyze_frame` | 按指定 profile 分析一帧 ADC 数据，识别两路频率、波形、幅相。 | FFT 实例、profile 和所有工作区不可为 NULL；DMA 缓冲区应已失效缓存。 |
| `signal_track_result` | 对已锁定结果进行频率一阶平滑。 | 当前锁定主流程不自动调用它更新 DDS。 |
| `signal_run_self_tests` | 执行合成输入回归。 | 适合启动诊断，不替代硬件测试。 |
| `signal_waveform_name` | 返回波形类型字符串。 | 用于日志。 |

## DMA 与 DDS

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `dma_init_s2mm` | 初始化 S2MM DMA 并确保无 SG 模式。 | 使用 `APP_DMA_RX_DEV_ID`。 |
| `dma_capture_frame` | 轮询接收一帧并负责错误恢复。 | 返回成功后再失效缓存。 |
| `dds_control_init` | 设置 BRAM 基址与初始提交序号。 | 每个控制对象启动时调用一次。 |
| `dds_control_from_component` | 将分析结果转换为 DDS 通道配置。 | 相位以度传入。 |
| `dds_control_commit` | 原子提交两通道 DDS 快照。 | 内部保证 `COMMIT_SEQ` 最后写入。 |
| `dds_control_adjust_b_phase` | 在保持频率的同时微调 B 相位。 | 仅在 DDS 已运行时使用。 |

## IQ、按键与诊断

| 函数 | 作用 | 使用要点 |
| --- | --- | --- |
| `iq_demodulator_init` | 绑定 IQ AXI-Lite 基址。 | 需要 BSP 导出的 `XPAR_IQ_DEMODULATOR_0_BASEADDR`。 |
| `iq_demodulator_measure` | 以单频窗口获得 I/Q 累加结果。 | 成功后立即使用结果；驱动已完成 W1C 确认。 |
| `button_input_init` | 初始化四个 EMIO GPIO 输入。 | 失败时不要进入按键主循环。 |
| `button_input_take_*_press` | 消费一次去抖后的按压。 | 函数会等待按键释放。 |
| `diagnostics_should_report` | 判断当前帧是否输出限频诊断。 | 只控制日志，不参与锁定判决。 |
| `diagnostics_report_adc_frame` | 输出 ADC 范围、均值、变化和饱和统计。 | 使用 `[ADC]` 前缀。 |
| `diagnostics_report_analysis` | 输出 FFT 分析结果和锁定判决。 | 使用 `[FFT]` 前缀。 |
| `diagnostics_report_signal_result` | 输出最终锁定的 A/B 分量。 | 使用 `[APP]` 前缀。 |
| `diagnostics_report_iq_measurement` | 输出归一化 IQ 幅值和相位。 | 使用 `[IQ]` 前缀，不改变测量结果。 |
| `diagnostics_report_dds_snapshot` | 输出 DDS BRAM 快照。 | 使用 `[DDS]` 前缀。 |

## 配置与 profile

| 函数/文件 | 作用 | 使用要点 |
| --- | --- | --- |
| `hardware_config.h` | 保存帧长、采样率、`XPAR_*`、GPIO 和 PL 寄存器协议。 | 比赛模式不得覆盖。 |
| `algorithm_config.h` | 保存 FFT/Hann、候选数量、容差、超时和默认确认次数。 | 不保存具体题目频带。 |
| `signal_profile_get` | 按 ID 返回只读 profile。 | 越界返回 NULL，不自动回退。 |
| `signal_profile_default` | 返回当前旧双分量分离 profile。 | 保持 20～100 kHz、5 kHz 栅格和 3 帧确认。 |
| `signal_profile_count` | 返回登记的 profile 数量。 | 包含尚未配置参数的预留项。 |
