# 2026 G PS 函数索引

以下仅列当前活动测量链路。旧 signal separator、DDC/IQ、DDS 和 modulation analysis 接口均为非活动历史模块。

## 信号分析

文件：`Identification_Processing_System/src/User/include/g26_signal_analysis.h`、`User/src/g26_signal_analysis.c`

| 接口 | 用途 |
| --- | --- |
| `g26_signal_analysis_init` | 初始化 CMSIS 4096 点快速实数 FFT。 |
| `g26_signal_analyze` | 从 4096 个 `s16` 样点识别 2/3 个谐波分量，并输出频率、峰值幅度、相位、模型 RMS、Upp 和归一化残差。 |
| `g26_signal_generate_waveform` | 按拟合结果生成模型波形，供后续显示或离线检查；当前未接 HMI。 |
| `g26_signal_analysis_self_test` | 运行算法内置的最小自检。自检存在不等于已完成板级验证。 |

主要结果类型为 `g26_signal_result_t`。每个分量给出谐波序号、频率、峰值幅度和相位；整体结果同时保存直流项与模型质量指标。具体字段名以头文件为准，文档不复制结构体定义。

## 测量任务

文件：`Identification_Processing_System/src/User/include/g26_measurement_app.h`、`User/src/g26_measurement_app.c`

| 接口 | 用途 |
| --- | --- |
| `g26_measurement_task` | FreeRTOS 单次测量任务：轮询按键，完成 DMA 帧采集、质量检查、算法调用、结果保持及清除重装。 |
| `g26_measurement_output` | 返回只读结果区；`valid=1` 后可读取分析结果以及 640 点的 1/3 周期模型波形。 |

该任务是当前应用唯一需要公开的入口，不为一次性状态机增加额外抽象。

## 复用的现有接口

| 模块 | 活动接口 |
| --- | --- |
| 按键 | `button_input_init`、`button_input_take_start_press`、`button_input_take_reset_press` |
| SG DMA | `dma_init_s2mm`、`dma_align_s2mm`、`dma_capture_frame`、`dma_last_s2mm_length_bytes`、`dma_shutdown_s2mm` |
| FIFO 监视 | `fifo_monitor_init`、`fifo_monitor_clear_sticky`、`fifo_monitor_snapshot` |
| 缓冲区 | `g_adc_raw_buffer` 及现有静态分析缓冲区；DMA 字按 `s16` 解释，不做 `u16 >> 4`。 |

## 配置契约

| 配置 | 当前值或含义 |
| --- | --- |
| 分析点数 | 4096 |
| 正式帧长度 | 8192 byte |
| ADC 采样率 | `5120060 Hz` |
| PL FIR 抽取 | 3 |
| PS 分析采样率 | `5120060 / 3 Hz` |
| 预热丢弃帧数 | 3 |
| 基波栅格 | 500 Hz |
| 放大链码值初始比例 | `0.1645 mV/code`，仅为 bring-up 标定旋钮 |
| 直连 ADC 板测比例 | 约 `2.44140625 mV/code`，切换接法时必须同步修改 |

算法已通过 Cortex-A9 QEMU 自检；Vitis 已用生成的 `-O2` 规则链接 Debug ELF，并由 Bootgen 生成 `BOOT.BIN`。实板采集和测量精度仍待验证。

正式帧质量判据固定为：实收长度严格等于 8192 byte，且正式帧期间 `blocked_reset` 计数不增长；`blocked_high_watermark` 只告警记录。
