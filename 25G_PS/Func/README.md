# 25G PS 功能文档

本文档集描述当前 2026 G 题 PS 单次测量主链。完整的跨 PS/PL 架构、校准
与板测状态见 [../../Doc/26G_当前架构与实测状态.md](../../Doc/26G_当前架构与实测状态.md)。

## 当前范围

- 输入是 PL FIR `/3` 后的 `4096 x signed16`、8192 byte 帧。
- PS 采样率为 `5120060 / 3 Hz`，FFT 频点间隔约 416.67 Hz。
- Hann + CMSIS RFFT 负责候选搜索，联合时域最小二乘负责最终幅相估计。
- 当前全局标定为 `2.3096181 mV/code`，并按频率插值补偿 10..500 kHz
  端到端响应。
- KEY1 启动一次测量，KEY2 清除并重新装填；完成时间约 80..340 ms。
- 当前输出串口诊断和只读测量结果，串口屏协议尚未实现。

## 当前验证

- 算法启动自检通过。
- 10..500 kHz、50 mVpeak 测试最大分量误差约 0.561 mV。
- 25 mVpeak 补测最大分量误差约 0.363 mV。
- 1/1.5/2 MHz、200 mVpp 干扰对 250/500 kHz 有效参数的最近实测影响
  小于 0.2 mV。
- 5 mVpeak、总 Upp 边界、不同相位和 4.62..5.62 MHz ADC 混叠窗口待测。

## 非活动历史模块

旧 signal separator、DDC/IQ、DDS 和 modulation analysis 不属于当前 G26
主链。它们不应接回 `main()`，也不应出现在当前系统框图中。
